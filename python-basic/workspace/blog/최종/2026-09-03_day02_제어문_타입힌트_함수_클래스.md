## 1. 제어문 (조건문 & 반복문)

| 분류 | 종류 | 설명 |
| --- | --- | --- |
| 조건문 | if, elif, else | 조건에 따라 코드 실행 분기 |
| 반복문 | for, while | 코드를 반복해서 실행 |

### 조건문 if

```python
# 기본형
if 조건식:
    조건이 참일 때 실행할 코드들...

# else 포함
if 조건식:
    조건이 참일 때 실행할 코드들...
else:
    조건이 거짓일 때 실행할 코드들...

# elif로 조건 여러 개
if 조건식1:
    조건1이 참일 때 실행할 코드들...
elif 조건식2:
    조건2가 참일 때 실행할 코드들...
else:
    모든 조건이 거짓일 때 실행할 코드들...
```

- 들여쓰기를 꼭 지켜야 한다.
- `else`는 옵션이며, 조건식 없이 바로 콜론(:)만 붙인다.
- `elif`는 조건이 여러 개일 때 사용한다.

### 반복문 loop

특정 조건을 만족할 때까지 동일한 코드를 반복 실행하는 구조입니다.

| 반복문 종류 | 사용 상황 |
| --- | --- |
| while | 조건이 참인 동안 계속 반복 |
| for | 특정 횟수나 반복 가능한 객체 순회 |

보조 제어문:

```python
break     # 루프를 강제 종료할 때 사용
continue  # 루프에서 특정 회차를 건너뛰고 싶을 때
```

### while문 구조

조건식이 `True`인 동안 계속 반복합니다.

```python

    실행할 코드들...
```

```python

    print(i)
    i += 1

    print(i)
    i += 10

    if i % 2 == 1: # 홀수 판단

    i += 1

    total += i # total에 i값 누적

# 문제5. 1 ~ 100까지 짝수들의 총 합 출력.

tot = 0
while i <= 100:
    if i % 2 == 0:
        tot += i
    i += 1
print("total: ", tot)
```

## 2. 타입 힌트(Type Hint)와 형 변환

### 타입 힌트란?

- 변수나 함수의 자료형을 사람이 보기 쉽게 적어주는 문법
- 실행에는 영향이 없고, 코드 가독성을 높이고 에러를 줄이는 데 도움을 준다.
- 파이썬은 동적 타입 언어라 자료형을 안 적어도 되지만, 명시적으로 적으면 더 안전하다.

### 기본형 타입 힌트

```python
변수명: 자료형 = 값
```

### 컬렉션 타입 힌트

| 자료형 | 예시 |
| --- | --- |
| `list[int]` | 정수 리스트 → `[1, 2, 3]` |
| `dict[str, int]` | 키는 문자열, 값은 정수인 딕셔너리 |
| `tuple[str, int]` | 문자열과 정수로 구성된 튜플 (각 위치별 타입 명시) |
| `tuple[str, ...]` | 동일한 타입 여러 개로 구성된 튜플 (`...` 사용) |
| `set[str]` | 문자열로 구성된 집합 |

### 동적 타입 힌트

```python
변수: 타입1 | 타입2 = 값
```

### Ellipsis(`...`) 사용하는 상황

| 사용 분야 | 예 | 설명 |
| --- | --- | --- |
| 슬라이싱 | `array[..., 0]` | 다차원 배열에서 전체 축 지정 |
| 타입 힌트 | `tuple[int, ...]` | 동일한 타입 요소가 반복되는 튜플 |
| 추상 메서드 | `def 함수명(): ...` | 내용 없이 메서드 정의할 때 `pass` 대신 사용 |
| 플레이스홀더 | `...` | 구현 전 임시 코드 (`pass` 대신) |

### 형 변환 (type conversion)

| 함수 | 설명 | 예 |
| --- | --- | --- |
| `int()` | 정수로 변환 | `int("100")` → 100, `int(3.9)` → 3 |
| `float()` | 실수로 변환 | `float("3.14")` → 3.14, `float(3)` → 3.0 |
| `str()` | 문자열로 변환 | `str(100)` → "100" |
| `list()` | 리스트로 변환 | `list((1, 2, 3))`, `list("hello")`, `list(set([1, 2, 3, 3]))` |
| `tuple()` | 튜플로 변환 | `tuple([1, 2, 3])` |
| `set()` | 중복 제거 | `set([1, 1, 2, 3])` → `{1, 2, 3}` |
| `dict()` | 딕셔너리로 변환 | `dict([('a', 1), ('b', 2)])`, `dict(zip(['a', 'b'], [1, 2]))` → `{'a': 1, 'b': 2}` |
| `bool()` | bool로 변환 | `bool(0)`, `bool("")`, `bool([])`, `bool({})`, `bool(None)` → False / `bool("False")`, `bool("0")`, `bool([0])` → True |

구조: `타입(변수 또는 데이터)`

## 3. 함수 (def)

### 함수란?

특정 작업을 수행하는 코드 블록에 이름을 붙여 재사용할 수 있도록 만든 것입니다.

```python
# 정의하기
def 함수이름():
    실행할 코드들...
    return 결과값

# 호출하기
함수이름()

# 매개변수가 있는 함수
def 함수이름(매개변수, 매개변수, ...):
    실행할 코드들...
    return 결과값

변수 = 함수이름(인자, 인자, ...)
```

매개변수와 리턴값의 유무에 따라 4가지 형태로 작성할 수 있고, 매개변수와 인자의 개수·순서는 원칙적으로 일치해야 합니다(단, 키워드 인자를 쓰면 순서를 바꿀 수 있습니다).

### 함수 타입 힌트 구조

```python
def 함수이름(매개변수1: 타입, 매개변수2: 타입, ...) -> 리턴타입:
    실행할 코드들...
    return 리턴값  # return이 없으면 리턴타입에 None을 적어주면 된다
```

- 각 매개변수 뒤에 `: 타입` 추가
- 리턴 타입은 소괄호와 콜론 사이에 `-> 리턴타입`
- 리턴 값이 없으면 `-> None`

### 매개변수 기본값

```python
def greeting(name="아무개"):
    print(f"안녕하세요, {name}님")
greeting()

# default 값이 있는 매개변수는 일반 매개변수 뒤쪽에 배치
def greeting(age, name="아무개"):
    print(f"안녕하세요, {age}세이신 {name}님")
greeting(20)
```

### 키워드 인자

```python
# 매개변수와 인자의 순서는 원칙적으로 일치해야 한다.
def info(name, age):
    print(f"{name}님의 나이는 {age}입니다.")
info("민식", 20)

# 키워드 인자를 사용하면 인자의 순서를 바꿀 수 있다.
info(age=20, name="민식")
```

### 가변 인자 `*args`, `**kwargs`

```python
# 넘겨주는 데이터가 여러 개일 때 하나의 매개변수로 받고 싶으면 *args 사용
def total(*nums):
    return sum(nums)

total(10, 20, 30, 40, 50)  # 150

def total(num, *args, age=1000):
    print(num, age, args)
    return sum(args)

total(10, 20, 30, 40, 50)  # 10 1000 (20, 30, 40, 50)
```

가변 인자는 일반 매개변수 뒤에 배치하고, default 값이 있는 매개변수는 가변 인자보다 뒤에 배치한다.

```python
def show_info(**kwargs):
    for key, value in kwargs.items():
        print(f"{key} : {value}")

show_info(name="Tom", age=20)
show_info(name="Tom", age=20, email="test@test.com")
```

`**kwargs`도 일반 매개변수 뒤에 배치한다.

### 리턴값 여러 개

## 4. 클래스 기초

### 클래스란?

- 클래스는 객체(Object)를 만들기 위한 틀(설계도)이다.
- 속성(변수)과 기능(메서드)을 정의한다.

### 클래스 정의 구조

```python
class 클래스명:
    ... 변수들, 메서드(클래스 내부의 함수)
```

클래스명의 첫 글자는 대문자로 만든다.

### 생성자

- 객체가 생성될 때 자동으로 한 번 실행되는 메서드
- 주로 속성(변수) 초기화에 사용
- 첫 번째 매개변수는 반드시 `self`

```python
class 클래스명:
    # 생성자
    def __init__(self, 매개변수들...):
        self.변수명 = 값
```

`__init__`: 생성자 메서드 / `self`: 객체 자신을 가리키는 키워드 / `self.name = 'pikachu'`처럼 객체에 저장되는 변수(인스턴스 변수)를 생성 / 메서드: 클래스 안에 정의된 함수

### 변수(속성)의 종류와 Scope

| 변수 종류 | 선언 위치 | 접근 방법 | 설명 | 생성 시점 | 소멸 시점 |
| --- | --- | --- | --- | --- | --- |
| 인스턴스 변수 | 클래스 내부 `self.변수명=값` | `참조변수.변수명` | 객체마다 개별적으로 존재 | `__init__` 등에서 선언 시 | 객체 소멸 시 |
| 클래스 변수 | 클래스 내부 `변수명=값` | `클래스명.변수명` | 클래스 전체에서 공유 | class 정의 시 | 클래스 소멸 시 |
| 지역 변수 | 함수/메서드 내부 | `변수명` | 함수 호출될 때만 존재 | 함수(메서드) 호출 시 | 함수(메서드) 종료 시 |
| 전역 변수 | 함수/클래스 외부 | `변수명` | 모듈(파일) 전체에서 사용 가능 | 파일 자체 import 시 | 프로그램 종료 시 |

```python
# 클래스 정의
class Person:
    # 클래스 변수
    nation = "Korea"
    # 생성자
    def __init__(self):
        print("생성자 호출!")
        # 인스턴스 변수
        self.name = ""
        self.age = 0
        # 지역변수
        x = 10

# 함수
def hello():
    # 지역변수
    y = 20

# 전역변수
abc = 10

# 객체 생성 : p1, p2, p3는 참조변수
p1 = Person()
p2 = Person()
p3 = Person()

print(Person.nation)
print(p1.nation)
print(p2.nation)
print(p3.nation)
print("-----------")

p1.nation = "UK"  # 인스턴스 변수화 (클래스 변수를 덮어쓰지 않고, p1만의 변수가 새로 생김)
print(Person.nation)
print(p1.nation)
print(p2.nation)
print(p3.nation)
```

클래스 변수는 모든 객체가 공유하지만, `p1.nation = "UK"`처럼 인스턴스에 직접 값을 대입하면 그 객체만의 인스턴스 변수가 새로 만들어져서 클래스 변수를 덮어쓰지 않는다는 점이 오늘 수업에서 제일 헷갈렸던 부분이었습니다.

## 오늘의 소감

어제는 문법 기초 위주였다면 오늘은 제어문 복습을 빠르게 끝내고 함수와 클래스로 넘어가면서 체감 진도가 확 빨라졌습니다. 특히 가변 인자(`*args`, `**kwargs`)와 매개변수 기본값의 위치 제약, 클래스 변수 vs 인스턴스 변수 차이는 자바에 익숙한 입장에서 새롭게 정리해야 할 개념이라 오늘 실습 코드를 여러 번 돌려보며 확인했습니다.

다음 포스팅에서는 오늘 실습 문제로 받은 인덱스 값 교환, 중첩 리스트 접근, 카페 주문 프로그램, Up/Down 게임 풀이를 정리해보겠습니다.
