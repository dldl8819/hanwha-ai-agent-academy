## 1. AI 서비스 백엔드 프로그래밍 실무 평가시험

### 문항1. 다음 코드의 출력 결과는?

```python
user = {"name": "김민준", "dept": "인사팀"}
print(user["dept"])
```

1. name
2. 김민준
3. 인사팀
4. dept

**정답: 3번** — 딕셔너리에서 대괄호 안에 키를 넣으면 그 키에 해당하는 값이 반환됩니다.

### 문항2. 오류가 발생해도 프로그램이 그 자리에서 멈추지 않도록 처리할 때 쓰는 파이썬 구문은?

1. if ~ else
2. for ~ in
3. while
4. try ~ except

**정답: 4번** — try 블록에서 오류가 나면 except 블록으로 넘어가 처리하고 프로그램은 계속 실행됩니다.

### 문항3. 다음 함수 선언에 대한 설명으로 옳은 것은?

```python
def get_name(user_id: int) -> str:
    ...
```

1. user_id는 문자열이고, 돌려주는 값은 정수다
2. user_id는 정수이고, 돌려주는 값은 문자열이다
3. 인자를 두 개 받는다
4. 돌려주는 값이 없다

**정답: 2번** — 콜론 뒤의 타입은 매개변수의 타입 힌트이고, 화살표 뒤의 타입은 반환값의 타입 힌트입니다.

### 문항4. 다음 코드의 출력 결과는?

```python
nums = [10, 20, 30, 40, 50]
print(nums[1:3])
```

1. [20, 30]
2. [10, 20]
3. [20, 30, 40]
4. [10, 20, 30]

**정답: 1번** — 슬라이싱은 시작 인덱스는 포함하고 끝 인덱스는 포함하지 않습니다. 인덱스 1부터 2까지, 즉 20과 30만 가져오게 됩니다.

### 문항5. 다음 코드의 출력 결과는?

```python
user = {"name": "김민준"}
print(user.get("dept", "미지정"))
```

1. None
2. KeyError가 발생한다
3. 미지정
4. dept

**정답: 3번** — get 메서드는 키가 없을 때 두 번째 인자로 넘긴 기본값을 반환하기 때문에 KeyError 없이 안전하게 처리됩니다.

### 문항6. 요청 본문을 받는 Pydantic 모델에 `age: int` 필드가 정의되어 있다. 클라이언트가 age 자리에 문자열 "스물"을 보냈다면 FastAPI의 응답은?

1. 200 OK — age가 0으로 바뀌어 처리된다
2. 500 — 서버가 오류로 멈춘다
3. 404 — 경로를 찾지 못한다
4. 422 — 검증 오류 내용을 함께 돌려준다

**정답: 4번** — FastAPI는 Pydantic으로 타입을 검증하기 때문에 타입이 맞지 않으면 자동으로 422 오류와 함께 검증 오류 내용을 돌려줍니다.

### 문항7. 다음 라우터에 GET /documents/DOC-HR-014 요청이 들어왔다. doc_id에 담기는 값은?

```python
@app.get("/documents/{doc_id}")
def get_document(doc_id: str):
    ...
```

1. /documents/DOC-HR-01
2. documents
3. DOC-HR-014
4. {doc_id}

**정답: 3번** — 경로 변수 `{doc_id}` 자리에 들어온 문자열 전체가 그대로 담깁니다.

### 문항8. documents 테이블에서 status 값이 '현행'인 행만 조회하는 SQL은?

1. `SELECT * FROM documents IF status = '현행';`
2. `SELECT * FROM documents WHERE status = '현행';`
3. `SELECT status FROM documents = '현행';`
4. `FILTER documents BY status = '현행';`

**정답: 2번** — 조건을 걸 때는 WHERE 절을 사용합니다.

### 문항9. SQLAlchemy에서 새 행을 추가하려고 `session.add(obj)`만 호출하고 끝냈다. 그 결과로 옳은 것은?

1. 그 즉시 데이터베이스에 저장된다
2. 표(table)가 자동으로 만들어진다
3. 오류가 발생해 프로그램이 멈춘다
4. `session.commit()`을 호출해야 실제로 저장된다

**정답: 4번** — add는 세션에 객체를 등록만 하는 것이고, 실제 데이터베이스 반영은 commit이 담당합니다.

### 문항10. 프로젝트를 SQLite에서 PostgreSQL로 옮길 때, 애플리케이션 쪽에서 주로 바꾸는 것은?

1. 코드에 있는 모든 SQL 문을 PostgreSQL 전용 문법으로 새로 쓴다
2. 파이썬 버전을 올린다
3. `.env`의 데이터베이스 접속 주소(DATABASE_URL) 한 줄
4. 화면(Streamlit) 코드 전체

**정답: 3번** — ORM을 사용하는 경우 SQL 문을 전부 새로 쓸 필요 없이 접속 주소만 바꿔주면 됩니다.

## 2. AI-Native 아키텍처 및 테스트 공학 평가시험

### 문항1. LLM은 무엇의 줄임말인가?

1. Large Language Model
2. Long Learning Machine
3. Linked Logic Model
4. Local Language Memory

**정답: 1번**

### 문항2. LLM이 사실이 아닌 내용을 사실인 것처럼 그럴듯하게 지어내는 현상을 무엇이라고 하는가?

1. 오버플로(overflow)
2. 디버깅(debugging)
3. 환각(hallucination)
4. 캐싱(caching)

**정답: 3번**

### 문항3. LLM이 글을 처리할 때 쪼개어 다루는 기본 단위이자, API 사용 요금을 계산하는 기준이 되는 것은?

1. 픽셀(pixel)
2. 토큰(token)
3. 바이트코드(bytecode)
4. 패킷(packet)

**정답: 2번**

### 문항4. 파이썬으로 만든 코드가 의도대로 동작하는지 자동으로 검사할 때 사용하는 도구는?

1. numpy
2. pandas
3. pytest
4. uvicorn

**정답: 3번**

### 문항5. pytest가 자동으로 찾아서 실행하는 테스트 함수의 이름 규칙으로 옳은 것은?

1. 이름이 test_로 시작한다
2. 이름이 check_로 시작한다
3. 이름이 _test로 끝난다
4. 이름 규칙은 따로 없다

**정답: 1번**

### 문항6. pytest로 만든 테스트 안에서 "결과가 기대한 값과 같은지" 확인할 때 쓰는 키워드는?

1. return
2. yield
3. import
4. assert

**정답: 4번**

### 문항7. "질문 30개와 각각에 기대하는 답"을 미리 정해 두고, 코드나 프롬프트를 고칠 때마다 같은 30개로 다시 점수를 재는 이유로 가장 알맞은 것은?

1. 질문을 매번 새로 만들면 사람이 번거롭기 때문에
2. 같은 시험지로 재야 고치기 전과 후를 견줄 수 있기 때문에
3. LLM이 그 문제를 외우게 하려고
4. 토큰 요금을 줄이려고

**정답: 2번**

### 문항8. LLM을 쓰는 기능을 테스트할 때, 일반 함수를 테스트할 때와 가장 크게 다른 점은?

1. LLM은 인터넷 연결 없이도 동작한다
2. LLM 호출은 언제나 즉시 끝난다
3. LLM 호출에는 비용이 들지 않는다
4. 같은 입력에도 매번 조금씩 다른 답이 나올 수 있어, 결과를 글자 그대로 비교하기 어렵다

**정답: 4번**

### 문항9. 규격만 정해 둔 것을 먼저 만들고, 실제 구현(Claude를 부르는 코드 / 가짜 응답을 돌려주는 코드)을 따로 두는 설계의 이점으로 가장 알맞은 것은?

```python
class LLMPort(Protocol):
    def answer(self, question: str) -> str: ...
```

1. 네트워크나 API 키 없이도 가짜 구현으로 바꿔 끼워 테스트할 수 있다
2. 코드가 자동으로 번역된다
3. 데이터베이스가 필요 없어진다
4. 프롬프트를 쓰지 않아도 된다

**정답: 1번**

### 문항10. LLM에게 "JSON 형식으로만 답하라"고 지시했는데, 형식이 깨진 답이 돌아왔다. 서비스가 취할 대응으로 가장 알맞은 것은?

1. 돌아온 그대로 사용자 화면에 보여준다
2. 형식을 검사해, 어긋나면 다시 요청하거나 미리 정해 둔 대체 응답으로 넘어간다
3. 서버를 재시작한다
4. 데이터베이스를 초기화한다

**정답: 2번**
