### 369 게임 (조건문)

각 자릿수에 3, 6, 9가 몇 개 있는지에 따라 박수 횟수를 다르게 출력하는 문제입니다.

```python
num = int(input("숫자: "))
count_369 = str(num).count('3') + str(num).count('6') + str(num).count('9')
if count_369 == 1:
    print("박수짝")
elif count_369 >= 2:
    print("박수짝짝")
else:
    print(num)
```

숫자를 문자열로 바꾼 뒤 `count()`로 각 숫자의 개수를 세는 방식이 리스트로 자릿수를 하나씩 분리하는 것보다 훨씬 간결합니다.

### 스택(Stack) 직접 구현 (자료구조)

파이썬 리스트를 내부 저장소로 쓰는 스택 클래스를 만드는 문제입니다.

```python
class Stack:
    def __init__(self, capacity):
        self._data = []
        self._capacity = capacity

    def push(self, value):
        if self.length() >= self._capacity:
            return False
        self._data.append(value)
        return True

    def pop(self):
        if self.length() == 0:
            return None
        return self._data.pop()

    def length(self):
        return len(self._data)
```

`list.append()`와 `list.pop()`이 이미 스택의 push·pop과 동일하게 동작한다는 걸 알고 나니, 왜 파이썬에서 스택을 별도 자료형 없이 리스트로 구현하는지 이해가 됐습니다.

### 추상 클래스 기반 단위 변환기 (클래스와 상속)

부모 클래스가 전체 흐름(입력 → 변환 → 출력)을 담당하고, 자식 클래스는 변환 공식만 제공하는 구조입니다.

```python
from abc import ABC, abstractmethod

class Converter(ABC):
    @abstractmethod
    def convert(self, value):
        pass

    @abstractmethod
    def unit_name(self):
        pass

    def run(self):
        value = float(input(self.prompt()))
        result = self.convert(value)
        print(f"변환 결과: {result}{self.unit_name()}입니다.")

class WonToDollar(Converter):
    def convert(self, value):
        return value / 1200

    def unit_name(self):
        return "달러"
```

`run()`이라는 공통 흐름은 부모 클래스에 한 번만 작성하고, 자식 클래스는 자신에게 필요한 부분(`convert`, `unit_name`)만 채워 넣는 구조입니다. 3일차에 배운 추상 클래스 개념이 실제로 어떻게 쓰이는지 보여주는 문제였습니다.

### TV 다단계 상속 (클래스와 상속)

`TV → ColorTV → IPTV`로 이어지는 다단계 상속을 구현하는 문제도 있었습니다.

```python
class TV:
    def __init__(self, size):
        self.size = size

class ColorTV(TV):
    def __init__(self, size, colors):
        super().__init__(size)
        self.colors = colors

class IPTV(ColorTV):
    def __init__(self, address, size, colors):
        super().__init__(size, colors)
        self.address = address
```

`IPTV` 객체 하나가 `TV`, `ColorTV`, `IPTV` 세 단계의 속성을 모두 가지는 걸 직접 만들어보면서, 3일차 포스팅에서 정리했던 다단계 상속 개념을 다시 한번 코드로 확인했습니다.
