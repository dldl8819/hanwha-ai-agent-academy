### 자료형(Data Type)

- 기본 자료형: 변수에 저장되는 값 한 개짜리 종류
- 복합 자료형: 여러 값을 한 번에 저장하는 구조(자료구조)

#### 기본 자료형

| 자료형 | 예시 | 설명 |
| --- | --- | --- |
| int | 10 | 정수형 |
| float | 3.14 | 실수형 |
| str | "hello" | 문자열형 |
| bool | True, False | 참/거짓 |
| NoneType | None | 아무 값도 없음 |

자료형은 `type(변수)`로 확인할 수 있습니다.

#### 숫자형(int, float)

| 항목 | 파이썬 사용 예 |
| --- | --- |
| 정수 | 123, -345, 0 |
| 실수 | 123.45, -1234.5, 3.4e10 |
| 8진수 | 0o34, 0o25 |
| 16진수 | 0x2A, 0xFF |

#### 문자형(str)

연속된 문자들의 나열이고, 순서가 있어서 인덱스 번호로 글자 한 개만 뽑아올 수 있습니다. 그리고 한 번 만들면 값을 바꿀 수 없는(immutable) 특징이 있습니다.

```python
"hello"
'hello'

# h e l l o
# 0 1 2 3 4 ← 인덱스 번호

hello[0] # -> 'h'
# 문자열 변수 또는 문자열 뒤에 [인덱스번호]를 붙이면 그 위치의 글자를 추출할 수 있음
```

#### 불 자료형(bool)

```python
True # 참
False # 거짓
```

### 복합 자료형(컬렉션)

| 자료형 | 예시 | 설명 |
| --- | --- | --- |
| list | [1, 2, 3] | 순서 있고 변경 가능한 자료 모음 |
| tuple | (1, 2, 3) | 순서 있지만 변경 불가능 |
| dict | {"name": "Alice"} | 키-값 쌍 |
| set | {1, 2, 3} | 중복 없는 집합 |

#### 리스트(list)

`[]`로 감싸서 만들고, 순서가 있어 인덱스를 사용할 수 있으며, 값을 자유롭게 추가·삭제할 수 있는(mutable) 자료형입니다.

주요 메서드:

```python
.append(값) # 맨 뒤에 값 추가
.insert(인덱스, 값) # 인덱스 위치에 값 추가
.remove(값) # 값 삭제
.pop() # 마지막 값 제거
.sort() # 정렬
```

- 인덱싱: 리스트 안의 특정 데이터 한 개를 조회 → `[인덱스]`
- 슬라이싱: 리스트 안의 여러 데이터를 잘라서 조회 → `[시작인덱스:끝인덱스]`

#### 튜플(tuple)

`( , )`로 감싸서 만들고, 데이터가 한 개일 때는 반드시 쉼표를 붙여야 튜플로 인식됩니다. 리스트와 달리 한 번 만들면 수정이 불가능(immutable)해서 읽기 전용 데이터에 적합하고, 리스트보다 속도가 빠릅니다. 함수나 메서드에서 여러 값을 한 번에 리턴할 때도 자주 사용됩니다.

```python
변수명 = (값,)
변수명 = (값1, 값2, 값3, ...)
변수명 = 값1, 값2, 값3, ...
```

인덱싱·슬라이싱은 리스트와 거의 동일하게 사용할 수 있습니다.

#### 딕셔너리(dict)

`{키: 값}` 형태로 데이터를 저장하고, 여러 쌍도 `{키1: 값1, 키2: 값2, ...}`처럼 저장할 수 있습니다. 파이썬 3.7부터는 순서도 보장됩니다. 키는 중복될 수 없지만 값은 중복 가능하고, 키를 이용해 값을 조회하는 구조입니다.

주요 메서드:

```python
.get(키) # 키로 값 조회
.keys() # 키 리스트 조회
.values() # 값 리스트 조회
.items() # 키-값 쌍 조회
.clear() # 데이터 전체 삭제
```

#### 집합(set)

`{}` 또는 `set()`으로 만들고, 순서가 없어 인덱스를 쓸 수 없는 대신 값이 자동으로 중복 제거됩니다. 그래서 중복 제거용 필터로 많이 쓰이고, 합집합·교집합·차집합 같은 집합 연산도 가능합니다.

주요 메서드:

```python
.add(값) # 값 추가
.discard(값) # 값 삭제
.remove(값) # 값 삭제
.clear() # 모든 값 삭제
.update(값) # 여러 값 수정/추가
```

집합 연산도 가능합니다.

```python
a = {1, 2, 3}
b = {3, 4, 5}
print(a | b) # 합집합 -> {1, 2, 3, 4, 5}
print(a & b) # 교집합 -> {3}
print(a - b) # 차집합 -> {1, 2}
```

## 연산자

연산자 종류에는 산술연산자, 비교연산자, 논리연산자, in 연산자, 삼항연산자, 대입연산자, 복합대입연산자가 있습니다.

### 산술 연산자

```python
+ - * /

/ : 실수로 결과 나옴 ex. 10 / 3 = 3.33333...
% : 나머지 값 구하기 ex. 10 % 3 = 1
// : 몫만 구해주는 연산자 ex. 10 // 3 = 3
```

### 비교 연산자

연산 결과가 bool 타입(True/False)으로 나옵니다.

```python
> 크다
>= 크거나 같다
< 작다
<= 작거나 같다
== 같다
!= 다르다
```

### 논리 연산자

비교 연산자와 동일하게 역시 결과가 bool 타입이고, 비교 연산식을 여러 개 묶어서 판단하고 싶을 때 씁니다.

```python
and # 양쪽 모두 참이어야 참, 하나라도 거짓이면 거짓
or # 하나라도 참이면 참, 둘 다 거짓이어야 거짓
not # 반전 (True -> False, False -> True)
```

### in 연산자

포함 여부를 True/False로 리턴합니다. 리스트뿐 아니라 문자열, 튜플, 딕셔너리(키 기준)에도 똑같이 쓸 수 있습니다.

```python
nums = [1, 2, 3, 4, 5]
print(3 in nums) # True
print(13 in nums) # False

string = "hello python"
print("lo py" in string) # True

dic = {'name': 'pika', 'age': 100}
print('name' in dic) # True (키만 확인)
print('pika' in dic.values()) # True (값 확인은 .values() 필요)
```

### 삼항 연산자

조건에 따른 값을 한 줄로 표현합니다.

```python
<참일 때 값> if <조건식> else <거짓일 때 값>

score = 50
result = "합격" if score >= 60 else "불합격"
print(result) # 불합격
```

### 대입 연산자 / 복합 대입 연산자

```python
= # 대입 연산자

+= -= *= /= %= # 복합 대입 연산자 (산술 + 대입)

i = i + 1 => i += 1
```

## 제어문 — 조건문과 반복문

| 분류 | 종류 | 설명 |
| --- | --- | --- |
| 조건문 | if, elif, else | 조건에 따라 코드 실행 분기 |
| 반복문 | for, while | 코드를 반복해서 실행 |

### 조건문 if

```python
# 기본형
if 조건식:
   조건이 참일 때 실행할 코드들...

# else 포함
if 조건식:
   조건이 참일 때 실행할 코드들...
else:
   조건이 거짓일 때 실행할 코드들...

# elif로 조건 여러 개
if 조건식1:
   조건1이 참일 때 실행할 코드들...
elif 조건식2:
   조건2가 참일 때 실행할 코드들...
else:
   모든 조건이 거짓일 때 실행할 코드들...
```

들여쓰기를 꼭 지켜야 하고, `else`는 옵션이라 생략 가능하며 조건식 없이 바로 콜론(:)을 붙이고, elif는 조건이 여러 개일 때 씁니다.

```python
score = 15
# score가 90점 이상이면 "A", 80점대면 "B", 70점대면 "C", 그 이하는 "재시험"
if score >= 90:
   print("A")
elif score >= 80:
   print("B")
elif score >= 70:
   print("C")
else:
   print("재시험")

# 중첩 조건
age = 20
is_student = True

if age >= 18:
   if is_student:
      print("성인이며 학생입니다.")
   else:
      print("그냥 성인입니다.")
else:
   print("미성년자 입니다.")
```

### 반복문 loop

특정 조건을 만족할 때까지 동일한 코드를 반복 실행하는 구조입니다.

| 반복문 종류 | 사용 상황 |
| --- | --- |
| while | 조건이 참인 동안 계속 반복 |
| for | 특정 횟수나 반복 가능한 객체 순회 |

보조 제어문:

```python
break # 루프를 강제 종료할 때 사용
continue # 루프에서 특정 회차를 건너뛰고 싶을 때
```

### while문

조건식이 `True`인 동안 계속 반복합니다.

```python
while 조건식:
   실행할 코드들...

i = 1 # 초기식
while i <= 5: # 조건식
   print(i)
   i = i + 1 # 증감식 (i += 1과 동일)

# 무한 반복 — 어느 시점엔 반드시 종료되도록 설계해야 함
while True:
   answer = input("아무것이나 입력(종료는 exit입력): ")
   if answer == "exit":
      break # while문을 강제 종료
   print(answer)
```

노션 노트를 그대로 받아쓰기보다 스스로 정리하라는 말씀이 계속 기억에 남는데, 오늘처럼 배운 내용을 블로그에 복습 삼아 남겨두면 저한테도 좋고 같은 과정을 준비하는 분들께도 도움이 될 것 같아 앞으로도 꾸준히 올려보려고 합니다.
