### 변수와 자료형
파이썬은 동적 타입 언어라 변수 선언 시 타입을 지정하지 않는다.

| 자료형 | 예시 | 설명 |
|---|---|---|
| int | 10 | 정수형 |
| float | 3.14 | 실수형 |
| str | "hello" | 문자열형 |
| bool | True, False | 참/거짓 |
| NoneType | None | 아무 값도 없음 |

복합 자료형:

| 자료형 | 예시 | 설명 |
|---|---|---|
| list | [1, 2, 3] | 순서 있고 변경 가능 |
| tuple | (1, 2, 3) | 순서 있지만 변경 불가 |
| dict | {"name": "Alice"} | 키-값 쌍 |
| set | {1, 2, 3} | 중복 없는 집합 |

- list: `.append()`, `.insert()`, `.remove()`, `.pop()`, `.sort()` / 인덱싱·슬라이싱 가능
- tuple: 값 1개면 `(값,)` 형태로 쉼표 필수, 수정 불가(immutable)
- dict: `.get()`, `.keys()`, `.values()`, `.items()`, `.clear()`
- set: `.add()`, `.discard()`, `.remove()`, `.clear()`, `.update()` / 합집합(`|`), 교집합(`&`), 차집합(`-`)

### 연산자
- 산술: `+ - * /`, `%`(나머지), `//`(몫)
- 비교: `> >= < <= == !=`
- 논리: `and`, `or`, `not`
- `in`: 포함 여부 확인 (list, str, tuple, dict 키)
- 삼항: `<참일 때 값> if <조건식> else <거짓일 때 값>`
- 대입/복합대입: `=`, `+= -= *= /= %=`

### 제어문
- 조건문: `if`, `elif`, `else`
- 반복문: `for`, `while` / 보조 제어문 `break`, `continue`
