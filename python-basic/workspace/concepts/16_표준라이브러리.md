# 표준 라이브러리 (Standard Library)

- 라이브러리(library) = 도서관. 전 세계 파이썬 개발자들이 만든 유용한 프로그램을 모아 놓은 것.
- 파이썬을 설치할 때 자동으로 함께 설치되므로 별도 설치 없이 `import`만 하면 바로 쓸 수 있다.

## 날짜/시간

### datetime.date

- 연, 월, 일로 날짜를 표현할 때 사용한다.

```python
import datetime

day1 = datetime.date(2021, 12, 14)
day2 = datetime.date(2023, 4, 5)

diff = day2 - day1
print(diff.days)   # 477 -- 두 날짜 사이의 일수

day = datetime.date(2021, 12, 14)
print(day.weekday())      # 1 -- 0=월요일 ... 6=일요일
print(day.isoweekday())   # 2 -- 1=월요일 ... 7=일요일
```

### time

| 함수 | 설명 |
| --- | --- |
| `time.time()` | 1970-01-01 00:00:00 기준으로 지난 시간을 초 단위 실수로 리턴 |
| `time.localtime()` | `time.time()`의 실수값을 연/월/일/시/분/초 형태로 변환 |
| `time.asctime()` | `localtime()` 결과를 알아보기 쉬운 문자열로 변환 |
| `time.ctime()` | 항상 현재 시간만 알아보기 쉬운 문자열로 리턴 |
| `time.strftime(포맷, localtime())` | 원하는 형식 코드로 날짜/시간 문자열 생성 |
| `time.sleep(초)` | 지정한 시간(초, 실수 가능)만큼 실행을 멈춤 — 반복문에서 일정 간격 두고 실행할 때 사용 |

```python
import time

for i in range(10):   # 1초 간격으로 0~9 출력
    print(i)
    time.sleep(1)
```

import math

math.gcd(60, 100, 80)   # 20 -- 최대공약수(gcd)
math.lcm(15, 25)         # 75 -- 최소공배수(lcm)

### random

| 함수 | 설명 |
| --- | --- |
| `random.random()` | 0.0 ~ 1.0 사이 실수 난수 |
| `random.randint(a, b)` | a ~ b 사이 정수 난수 |
| `random.choice(lst)` | 리스트에서 무작위로 하나 선택 |
| `random.sample(lst, k)` | 리스트에서 서로 다른 k개를 무작위로 뽑음(원본 리스트를 섞는 용도로도 사용) |

```python
import random

def random_pop(data):
    number = random.choice(data)
    data.remove(number)
    return number

data = [1, 2, 3, 4, 5]
random.sample(data, len(data))   # 리스트를 무작위로 섞은 새 리스트
```

## 반복자(iterator) 도구

### itertools.zip_longest

- 내장 함수 `zip`과 동작이 같지만, 길이가 다른 데이터를 묶을 때 짧은 쪽을 `fillvalue`로 채운다.

```python
import itertools

students = ['한민서', '황지민', '이영철', '이광수', '김승민']
snacks = ['사탕', '초콜릿', '젤리']

result = itertools.zip_longest(students, snacks, fillvalue='새우깡')
print(list(result))
```

### itertools.permutations / itertools.combinations

- `permutations(iterable, r)`: r개를 뽑는 **순열**(순서를 구분).
- `combinations(iterable, r)`: r개를 뽑는 **조합**(순서를 구분하지 않음).

```python
import itertools

list(itertools.permutations(['1', '2', '3'], 2))
# [('1','2'), ('1','3'), ('2','1'), ('2','3'), ('3','1'), ('3','2')]

len(list(itertools.combinations(range(1, 46), 6)))
# 8145060 -- 로또 번호(1~45 중 6개) 전체 조합 개수
```

### functools.reduce

- 함수를 반복 가능한 데이터에 왼쪽부터 순서대로 누적 적용해서 값 하나로 줄인다.

```python
import functools

data = [1, 2, 3, 4, 5]
result = functools.reduce(lambda x, y: x + y, data)
print(result)   # 15 -- ((((1+2)+3)+4)+5)와 동일
```

### operator.itemgetter

- `sorted()`의 `key`에 적용해서 다양한 기준으로 정렬할 때 쓴다.

```python
from operator import itemgetter

students = [("jane", 22, 'A'), ("dave", 32, 'B'), ("sally", 17, 'B')]
sorted(students, key=itemgetter(1))   # 나이(인덱스 1) 기준 정렬

students_dict = [{"name": "jane", "age": 22}, {"name": "sally", "age": 17}]
sorted(students_dict, key=itemgetter('age'))   # 딕셔너리는 키 이름으로 지정
```

## 파일/디렉터리 관련

| 모듈 | 설명 | 예 |
| --- | --- | --- |
| `shutil` | 파일 복사/이동 | `shutil.copy("c:/doit/a.txt", "c:/temp/a.txt.bak")` |
| `glob` | 디렉터리 안 파일 목록을 패턴(`*`, `?`)으로 검색 | `glob.glob("c:/doit/mark*")` |
| `tempfile` | 임시 파일 생성. `mkstemp()`는 이름만, `TemporaryFile()`은 파일 객체까지 생성(`close()` 시 자동 삭제) | `tempfile.mkstemp()` |
| `zipfile` | 여러 파일을 zip으로 묶거나 해제 | 아래 예시 참고 |

```python
import zipfile

with zipfile.ZipFile('mytext.zip', 'w') as myzip:
    myzip.write('a.txt')
    myzip.write('b.txt')

with zipfile.ZipFile('mytext.zip') as myzip:
    myzip.extractall()          # 전체 해제
    # myzip.extract('a.txt')    # 특정 파일만 해제
```

- `zipfile`의 `compression` 옵션: `ZIP_STORED`(무압축, 빠름) / `ZIP_DEFLATED`(일반 zip, 호환성 좋음) / `ZIP_BZIP2`, `ZIP_LZMA`(압축률 높지만 느림). `compresslevel`은 1(빠름·저압축)~9(느림·고압축).

## 데이터 직렬화

### pickle

- 객체를 형태 그대로 유지하며 파일에 저장/불러오기.

```python
import pickle

f = open("test.txt", 'wb')
data = {1: 'python', 2: 'you need'}
pickle.dump(data, f)   # 저장
f.close()

f = open("test.txt", 'rb')
data = pickle.load(f)   # 원래 객체 상태 그대로 복원
```

### json

```python
import json

# 딕셔너리 -> JSON 문자열
d = {"name": "홍길동", "birth": "0525", "age": 30}
json_data = json.dumps(d, ensure_ascii=False)   # ensure_ascii=False: 한글이 유니코드 이스케이프로 안 바뀌게 함
print(json_data)

# JSON 문자열 -> 딕셔너리
json.loads(json_data)

# 파일로 저장/읽기
with open('myinfo.json', 'w') as f:
    json.dump(d, f)
with open('myinfo.json') as f:
    data = json.load(f)

print(json.dumps(d, indent=2, ensure_ascii=False))   # indent로 보기 좋게 정렬
```

## 기타

| 모듈 | 설명 |
| --- | --- |
| `threading` | 한 프로세스 안에서 여러 작업을 동시에 수행(스레드). `Thread(target=함수)`로 생성, `.start()`로 실행, `.join()`으로 종료 대기. 초보자에게는 난이도가 있는 주제. |
| `traceback` | 오류 발생 위치를 추적. `except` 블록에서 `traceback.format_exc()`로 상세 오류 내용 출력 가능 |
| `urllib` | URL을 읽고 요청을 보낼 때 사용 (`urllib.request.urlopen(...)`) |
| `webbrowser` | 파이썬에서 시스템 브라우저를 열 때 사용 (`webbrowser.open('http://python.org')`) |
