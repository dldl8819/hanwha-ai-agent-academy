# 파일 입출력 (File I/O)

## 기본 구조

### 파일 열기

```python
open(파일경로, 모드)
```

| 모드 | 설명 |
| --- | --- |
| `'r'` | 읽기 (read) |
| `'w'` | 쓰기 (write, 기존 내용 삭제) |
| `'a'` | 추가 (append) |
| `'x'` | 새 파일 생성 (이미 있으면 에러) |
| `'b'` | 바이너리 모드 (예: `'rb'`) |
| `'t'` | 텍스트 모드 (기본값) |

## 파일 쓰기 (write)

- `open()`만 별도로 사용하는 것은 비추천, `with-open` 구문을 활용한다.

```python
# 비추천
f = open(파일경로, 'w', encoding="utf-8")
f.write(내보낼 데이터값)
...
f.close()
```

- `with-open` 구문을 사용하면 해당 블록 코드가 완료되었을 때 자동으로 `close()` 처리를 해준다.
- `'w'` 모드는 기존에 작성된 내용이 있으면 **삭제된다** (주의!).

```python
with open(파일경로, 'w', encoding="utf-8") as f:
    f.write(내보낼 데이터값)
```

### 예시 (day03/ex22.py)

```python
with open("Heifam.txt", "w", encoding="utf-8") as f:
    f.write("안녕하세요.\n")
    f.write("헤이팸 유튜브 구독과 좋아요 알림설정까지 해주시면 큰 힘이 됩니다.\n")
    f.writelines(["Hei, ", "HeiFam"])   # writelines는 개행을 자동으로 넣지 않으므로 \n을 직접 작성해야 함
    print("유튜브 : \t https://www.youtube.com/@Hei-minsik", file=f)   # print()는 자동 개행됨
```

## 파일 읽기 (read)

```python
with open(파일경로, 'r', encoding="utf-8") as f:
    s = f.read()   # 전체 문자열을 하나로 리턴

with open(파일경로, 'r', encoding="utf-8") as f:
    s = f.readlines()   # 파일을 줄 단위로 읽어서 리스트로 리턴

with open(파일경로, 'r', encoding="utf-8") as f:
    for line in f:   # 대용량 파일은 한 줄씩 읽는 게 유리
        print(line.strip())   # strip()으로 각 줄 끝에 붙은 개행 문자를 없앰
```

## 파일에 이어서 쓰기

```python
with open(파일경로, 'a', encoding='utf-8') as f:
    f.write(....)
```

### 예시 (day03/ex22.py)

```python
with open("Heifam.txt", 'a', encoding='utf-8') as f:
    f.write("홈페이지 : \t https://heifam.co.kr")
```

## 파일 존재 여부 확인

```python
import os

if os.path.exists(파일경로):
    # 파일이 존재하면, ...
    print("파일이 있습니다")
else:
    # 파일이 존재하지 않다면, ...
    print("파일이 없습니다")
```

- 존재하지 않는 파일을 `open(..., 'r')`로 바로 열면 `FileNotFoundError`가 발생하므로, 읽기 전에 미리 확인하면 에러를 방지할 수 있다.

## 경로

- 상대 경로라면, 기준이 되는 위치(현재 작업 디렉토리)가 어디인지 항상 확인해야 한다.
- 운영체제에 따라 경로 구분자 작성 방법이 다르다 (`\` vs `/`) → 파이썬이 제공하는 `Path`를 사용하면 해결된다.

### 상대 경로 표기법

```python
.     현재 폴더
..    상위 폴더
../.. 두 단계 위
```

### 절대 경로 표기법 (루트부터 전부 작성)

```python
"C:\myfolder\workspace\a.txt"
"/Users/사용자명/Documents/workspace/a.txt"
```

### `pathlib`의 `Path`

```python
from pathlib import Path

print(Path(__file__).resolve())                # 파일 경로
print(Path(__file__).resolve().parent)          # 파일의 부모
print(Path(__file__).resolve().parent.parent)   # 파일의 2단계 상위 (프로젝트 ROOT)
```

- 경로 조합은 `/` 연산자로 처리한다. OS에 맞는 구분자로 알아서 바꿔주기 때문에 문자열 덧셈(`+`)은 사용하지 않는다.
- 윈도우에서 경로를 문자열로 직접 작성하면(`"C:\work\text\newfile.txt"`) `\t`, `\n` 같은 이스케이프 문자와 충돌할 위험이 있다. `Path`를 쓰면 이런 문제도 피할 수 있다.

### 예시 (day03/ex24.py)

```python
from pathlib import Path

ROOT = Path(__file__).resolve().parent.parent
target = ROOT / "Heifam.txt"

if os.path.exists(target):
    with open(target, 'r', encoding='utf-8') as f:
        print(f.read())
else:
    print("파일이 없습니다")
```

- `Heifam.txt`는 `.gitignore`에 등록되어 저장소에 커밋되지 않으므로, 새로 클론한 환경에서는 파일이 없을 수 있다. `os.path.exists()`로 먼저 확인해야 `FileNotFoundError` 없이 안전하게 실행된다.
