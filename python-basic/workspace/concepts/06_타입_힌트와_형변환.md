# 타입 힌트(Type Hint)와 형 변환

## 타입 힌트란?
- 변수나 함수의 자료형을 사람이 보기 쉽게 적어주는 문법.
- 실행에는 영향이 없고, **코드 가독성을 높이고 에러를 줄이는 데** 도움을 준다.
- 파이썬은 동적 타입 언어라 변수 선언할 때 자료형을 기술하지 않아도 되지만, 명시적으로 자료형을 적으면 더 안전하다.

## 기본형 타입 힌트
```python
변수명: 자료형 = 값
```

## 컬렉션 타입 힌트

| 자료형 | 예시 |
| --- | --- |
| `list[int]` | 정수 리스트 → `[1, 2, 3]` |
| `dict[str, int]` | 키는 문자열, 값은 정수인 딕셔너리 |
| `tuple[str, int]` | 문자열과 정수로 구성된 튜플 (각 위치별 타입 명시) |
| `tuple[str, ...]` | 동일한 타입 여러 개로 구성된 튜플 (ellipsis `...` 사용) |
| `set[str]` | 문자열로 구성된 집합 |

## 동적 타입 힌트
```python
변수: 타입1 | 타입2 = 값
```

## Ellipsis(`...`) 사용하는 상황

| 사용 분야 | 예 | 설명 |
| --- | --- | --- |
| 슬라이싱 | `array[..., 0]` | 다차원 배열에서 전체 축 지정 |
| 타입 힌트 | `tuple[int, ...]` | 동일한 타입 요소가 반복되는 튜플 |
| 추상 메서드 | `def 함수명(): ...` | 내용 없이 메서드 정의할 때 `pass` 대신 사용 |
| 플레이스홀더 | `...` | 구현 전 임시 코드 (`pass` 대신) |

## 형 변환 (type conversion)

| 함수 | 설명 | 예 |
| --- | --- | --- |
| `int()` | 정수로 변환 | `int("100") → 100`, `int(3.9) → 3` |
| `float()` | 실수로 변환 | `float("3.14") → 3.14`, `float(3) → 3.0` |
| `str()` | 문자열로 변환 | `str(100) → "100"` |
| `list()` | 리스트로 변환 | `list((1, 2, 3))`, `list("hello")`, `list(set([1, 2, 3, 3]))` |
| `tuple()` | 튜플로 변환 | `tuple([1, 2, 3])` |
| `set()` | 중복 제거 | `set([1, 1, 2, 3]) → {1, 2, 3}` |
| `dict()` | 딕셔너리로 변환 | `dict([('a', 1), ('b', 2)])`, `dict(zip(['a', 'b'], [1, 2])) → {'a': 1, 'b': 2}` |
| `bool()` | bool로 변환 | `bool(0)`, `bool("")`, `bool([])`, `bool({})`, `bool(None)` → False / `bool("False")`, `bool("0")`, `bool([0])` → True |

구조: `타입(변수 또는 데이터)`
