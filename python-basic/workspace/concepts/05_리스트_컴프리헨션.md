# 리스트 컴프리헨션 (List Comprehension)

반복문을 한 줄로 줄여서 리스트를 만들 수 있다.

## 구조
```python
[표현식 for 변수 in 반복가능한 값]

[표현식 for 변수 in 반복가능한 값 if 조건식]
```

## 예시

```python
nums = [1, 2, 3, 4, 5]
squares = [n*n for n in nums]
# for문으로 작성하면:
sq = []
for n in nums:
    sq.append(n*n)

# 조건 포함 — nums 중 짝수만 가져오기
even_nums = [n for n in nums if n % 2 == 0]

# 문자열 처리
words = ['oops', 'soul', 'minsik']
caped = [word.upper() for word in words]

# 중첩 for문 — 다중 리스트(matrix)를 1차원으로 풀기
matrix = [[10, 20], [30, 40]]
flattened = [num for row in matrix for num in row]
```

## 보조 제어문 복습
```python
# break
for i in range(1, 10):
    if i == 5:
        break
    print(i)

# continue
for i in range(1, 10):
    if i == 5:
        continue
    print(i)
```
