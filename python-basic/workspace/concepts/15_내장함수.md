# 내장 함수 (Built-in Functions)

- 파이썬 내장(built-in) 함수는 모듈과 달리 `import`가 필요 없어서 아무런 설정 없이 바로 사용할 수 있다.
- 이미 있는 기능을 다시 만들 필요 없다는 원칙(Don't Reinvent the Wheel)에 따라, 자주 필요한 동작들은 내장 함수로 미리 제공된다.

## 숫자 관련

| 함수 | 설명 | 예 |
| --- | --- | --- |
| `abs(x)` | 절댓값 리턴 | `abs(-3)` → `3` |
| `divmod(a, b)` | `a`를 `b`로 나눈 몫과 나머지를 튜플로 리턴 | `divmod(7, 3)` → `(2, 1)` (`7 // 3`과 `7 % 3` 결과와 동일) |
| `pow(x, y)` | `x`를 `y`제곱한 값 리턴 | `pow(2, 4)` → `16` |
| `round(number[, ndigits])` | 반올림, `ndigits`는 반올림할 소수점 자릿수 | `round(4.6)` → `5` |
| `hex(x)` | 정수를 16진수 문자열로 변환 | `hex(234)` → `'0xea'` |
| `oct(x)` | 정수를 8진수 문자열로 변환 | `oct(34)` → `'0o42'` |
| `int(x)` | 문자열/소수를 정수로 변환. `int(x, radix)`는 radix진수 문자열을 10진수로 변환 | `int('3')` → `3`, `int('1A', 16)` → `26` |

## 참/거짓 판단

| 함수 | 설명 | 예 |
| --- | --- | --- |
| `all(x)` | 반복 가능한 데이터의 요소가 **모두** 참이면 `True` | `all([1, 2, 3])` → `True`, `all([1, 2, 0])` → `False`, `all([])` → `True` |
| `any(x)` | 요소 중 **하나라도** 참이면 `True`, 모두 거짓이면 `False` | `any([0, ""])` → `False`, `any([])` → `False` |
| `isinstance(object, class)` | 객체가 해당 클래스의 인스턴스인지 확인 | `isinstance(a, Person)` |

## 문자/문자열 관련

| 함수 | 설명 | 예 |
| --- | --- | --- |
| `chr(i)` | 유니코드 숫자 값 → 그 문자 | `chr(97)` → `'a'`, `chr(44032)` → `'가'` |
| `ord(c)` | 문자 → 유니코드 숫자 값 (`chr`의 반대) | `ord('a')` → `97` |
| `str(object)` | 객체를 문자열로 변환 | `str(3)` → `'3'` |
| `len(s)` | 길이(요소 개수) | `len("python")` → `6` |

## 컬렉션(반복 가능한 데이터) 관련

| 함수 | 설명 | 예 |
| --- | --- | --- |
| `list(iterable)` | 리스트로 변환 | `list("python")` → `['p','y','t','h','o','n']` |
| `tuple(iterable)` | 튜플로 변환 (입력이 이미 튜플이면 그대로 리턴) | `tuple("abc")` → `('a','b','c')` |
| `max(iterable)` | 최댓값 | `max([1, 2, 3])` → `3` |
| `min(iterable)` | 최솟값 | `min([1, 2, 3])` → `1` |
| `sum(iterable)` | 합계 | `sum([1, 2, 3])` → `6` |
| `sorted(iterable)` | 정렬된 결과를 새 리스트로 리턴 | `sorted([3, 1, 2])` → `[1, 2, 3]` |
| `range([start,] stop [,step])` | 범위를 반복 가능한 객체로 생성 | `list(range(5))` → `[0,1,2,3,4]`, `list(range(1,10,2))` → `[1,3,5,7,9]` |
| `enumerate(x)` | 인덱스와 값을 함께 순회 (`for i, v in enumerate(lst)`) | `list(enumerate(['a','b']))` → `[(0,'a'), (1,'b')]` |
| `zip(*iterable)` | 동일한 개수로 이루어진 여러 데이터를 짝지어 묶음 | `list(zip([1,2],[3,4]))` → `[(1,3), (2,4)]` |

## 함수형 도구

| 함수 | 설명 | 예 |
| --- | --- | --- |
| `map(f, iterable)` | 각 요소에 함수 `f`를 적용한 결과 리턴 | `list(map(lambda x: x*2, [1,2,3]))` → `[2,4,6]` |
| `filter(f, iterable)` | 함수 `f`의 결과가 참인 요소만 걸러서 리턴 | `list(filter(lambda x: x>0, [1,-3,2]))` → `[1,2]` |
| `eval(expression)` | 문자열로 된 코드(표현식)를 실행한 결과 리턴 | `eval('1 + 2')` → `3` |

## 객체/타입 관련

| 함수 | 설명 | 예 |
| --- | --- | --- |
| `type(object)` | 자료형 확인 | `type("abc")` → `<class 'str'>` |
| `dir(x)` | 객체가 가진 변수·함수(메서드) 목록 확인 | `dir([1,2,3])` → `['append', 'count', ...]` |
| `id(object)` | 객체의 고유 주솟값(레퍼런스) 확인 | `id(a)` |

## 입출력 관련

| 함수 | 설명 | 예 |
| --- | --- | --- |
| `input([prompt])` | 사용자 입력을 받음. 인수로 문자열을 주면 그게 프롬프트로 표시됨 | `input("Enter: ")` |
| `open(filename, [mode])` | 파일을 열어 파일 객체 리턴. `mode` 생략 시 기본값은 읽기(`'r'`) | `open("data.txt", "w")` |

`open()`의 mode 종류는 [13_파일입출력](13_파일입출력.md)에서 다룬 내용과 동일하다(`w`/`r`/`a`/`b` 등).
