# 패키지 (Package)

## 개념

- 여러 모듈을 폴더로 묶은 것.
- 폴더 안에 `__init__.py` 파일이 있으면 패키지로 인식한다.

### 디렉토리 구조 예시

```
my_package/     # 패키지
  __init__.py   # 패키지 초기화 파일 (내용은 비워도 됨)
  calculator.py # 모듈
  converter.py  # 모듈
  ...
```

## 사용법

```python
# my_package/calculator.py
def add(a, b):
    return a + b
```

```python
# main.py
from my_package import calculator

print(calculator.add(1, 2))
```

### 주의점

- 패키지 안의 모듈을 스크립트처럼 직접 실행하면 `ImportError`(상대 임포트 관련 오류)가 발생할 수 있다.
- 반드시 패키지 바깥의 다른 파일에서 `import`로 불러서 사용해야 한다.

### import 절대 경로와 상대 경로

- **절대 경로**
  - `from my_package import mod`
  - 프로젝트 루트 기준으로 전체 경로를 명시.
- **상대 경로**
  - `from . import mod`
  - 현재 패키지(폴더) 기준으로 상대적으로 명시. (`.`은 현재 폴더, `..`은 상위 폴더)
