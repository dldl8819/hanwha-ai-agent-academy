# 추상 클래스와 추상 메서드 (Abstract Class / Abstract Method)

- 추상 = 내용물 없이 정의하는 것. 실제 동작 코드는 자식 클래스가 채워 넣는다.

## abc 모듈

- `abc` (Abstract Base Classes) = 추상 기반 클래스의 약자.
- 표준 라이브러리에 포함되어 있어서 추가 설치 없이 바로 사용 가능.
- 최상단에 `from abc import ABC, abstractmethod`로 가져와 사용한다.

## ABC 클래스

- `abc.ABC`는 추상 클래스를 만들기 위한 부모 클래스.
- 개발자가 만드는 클래스가 추상 클래스라는 것을 알려주는 역할을 한다.

## `@abstractmethod`

- 추상 메서드(내용물이 없는 껍데기 메서드, 설계 단계에서 주로 활용) 위에 붙이는 데코레이터.
- `@abstractmethod`가 붙은 메서드는 자식 클래스에서 **반드시 구현**해야 한다.
- 구현하지 않고 인스턴스를 생성하려 하면 `TypeError: Can't instantiate abstract class ... with abstract method ...` 오류가 발생한다.

## 예시 (day03/ex21.py)

```python
from abc import ABC, abstractmethod

class Animal(ABC):
    @abstractmethod
    def sound(self):
        pass

class Cat(Animal):
    def sound(self):
        print("야옹~~")

class Dog(Animal):
    def sound(self):
        print("멍멍!!")

dog = Dog()
dog.sound()   # 멍멍!!

cat = Cat()
cat.sound()   # 야옹~~
```

- `Animal`은 `sound()`의 구현 없이 "이 메서드는 반드시 채워야 한다"는 설계만 강제한다.
- `Cat`, `Dog`는 각각 `sound()`를 구현했기 때문에 정상적으로 인스턴스를 생성하고 호출할 수 있다.
- 만약 자식 클래스가 `sound()`를 구현하지 않고 인스턴스를 생성하려 하면 `TypeError`가 발생한다.
