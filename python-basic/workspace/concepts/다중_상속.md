# 다중 상속 (Multiple Inheritance)

- 파이썬은 여러 개의 부모 클래스를 동시에 상속받을 수 있다.
- `class 자식클래스(부모클래스1, 부모클래스2, ...)` 형태로 작성한다.

## 구조

```python
class D(A, B, C):
    pass
```

## 예시 (day03/ex20.py)

```python
class A:
    def __init__(self):
        print("A 생성자")

    def a(self):
        pass

class B:
    def __init__(self):
        print("B 생성자")

    def b(self):
        pass

class C:
    def __init__(self):
        print("C 생성자")

    def c(self):
        pass

class D(A, B, C):
    def __init__(self):
        print("D 생성자")

    def d(self):
        pass

a1 = A()
b1 = B()
c1 = C()
d1 = D()   # "D 생성자"만 출력됨 (A/B/C 생성자는 호출 안 됨)

d1.a()  # A의 메서드도 사용 가능
d1.b()  # B의 메서드도 사용 가능
d1.c()  # C의 메서드도 사용 가능
d1.d()
```

## 핵심 포인트

- `D`가 `A, B, C`를 모두 상속받아도, **`D`가 자기 `__init__`을 정의하면 자기 생성자만 실행된다.** `d1 = D()`를 해도 콘솔에는 "D 생성자"만 찍히고, "A 생성자"/"B 생성자"/"C 생성자"는 찍히지 않는다.
- 반대로 메서드(`a()`, `b()`, `c()`)는 `D`가 따로 정의하지 않았기 때문에, 상속받은 그대로 부모의 것을 사용할 수 있다.
- 즉 **생성자(`__init__`)도 결국 메서드이기 때문에, [[상속]] 문서의 오버라이딩 규칙을 그대로 따른다** — 자식이 재정의하면 자식 것만 실행되고, 부모 것을 같이 실행하려면 `super().__init__()`을 명시적으로 호출해야 한다.
- 만약 `D`가 `__init__`을 아예 정의하지 않았다면, 파이썬은 MRO(Method Resolution Order)에 따라 상속 순서상 **가장 먼저 적힌 부모(`A`)의 `__init__`**을 찾아 호출한다. (B, C의 생성자는 여전히 자동 호출되지 않는다.)
