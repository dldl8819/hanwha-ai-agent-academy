# 반복문 (loop)

특정 조건을 만족할 때까지 동일한 코드를 반복 실행하는 구조.

| 반복문 종류 | 사용 상황 |
| --- | --- |
| `while` | 조건이 참인 동안 계속 반복 |
| `for` | 특정 횟수나 반복 가능한 객체 순회 |

## 보조 제어문
```python
break     # 루프를 강제 종료할 때 사용
continue  # 루프에서 특정 회차를 건너뛰고 싶을 때
```

## while문
조건식이 `True`인 동안 계속 반복한다.

```python
while 조건식:
    실행할 코드들...

i = 1        # 초기식
while i <= 5:  # 조건식
    print(i)
    i = i + 1  # 증감식 (i += 1과 동일)

# 무한 반복 — 어느 시점엔 반드시 종료되도록 설계해야 함
while True:
    answer = input("아무것이나 입력(종료는 exit입력): ")
    if answer == "exit":
        break  # while문을 강제 종료
    print(answer)
```

### 복습 문제 (day01/ex09.py 풀이)
```python
# 문제1. 0 ~ 15까지 출력
i = 0
while i <= 15:
    print(i)
    i += 1

# 문제2. 0 ~ 100까지 10단위로 출력. ex. 0 10 20 30 ...
i = 0
while i <= 100:
    print(i)
    i += 10

# 문제3. 1 ~ 50까지 중 홀수만 출력.
i = 1
while i < 50:
    if i % 2 == 1:
        print(i)
    i += 1

# 문제4. 1 ~ 50까지의 총 합을 출력.
i = 1
total = 0
while i <= 50:
    total += i
    i += 1
print("total: ", total)

# 문제5. 1 ~ 100까지 짝수들의 총 합 출력.
i = 1
tot = 0
while i <= 100:
    if i % 2 == 0:
        tot += i
    i += 1
print("total: ", tot)
```

## for (in)문
```python
for 변수 in 반복가능한데이터:
    반복해 실행할 코드들...
```
> `list`, `str`, `tuple`, `range` 등 반복 가능한 객체를 순서대로 탐색한다.

### `range()` 함수
```python
range(끝)              # 0 ~ 끝-1까지 1씩 증가
range(시작, 끝)         # 시작값부터 끝-1까지 1씩 증가
range(시작, 끝, 간격)   # 시작부터 끝-1까지 간격만큼 증가
```

### dict 반복
```python
info = {'name': 'heifam', 'age': 20, 'height': 190.5}

for i in info:
    print(i)  # 키만 출력됨

for v in info.values():
    print(v)  # 값 출력

for k, v in info.items():  # Key-Value 쌍으로 반복 (가장 많이 사용)
    print(k, "/", v)
```

### `enumerate()` 함수
인덱스, (키, 값)을 함께 필요할 때 사용. Sequence는 default로 0부터 시작.
```python
for i, (k, v) in enumerate(info.items()):
    print(i, k, v)

for i, (k, v) in enumerate(info.items(), start=1):
    print(i, k, v)
```

## 패킹/언패킹, 데이터 스왑
```python
# List
lst = [1, 2, 3]
a, b, c = lst

# Tuple
lst = (1, 2, 3)
a, b, c = lst

# 2개면 소괄호 없이도 가능 (패킹)
nums = 10, 20
aa, bb = nums  # 언패킹

# 데이터 스왑 — 임시변수 없이 교환
int1, int2 = 100, 200
int1, int2 = int2, int1
```
