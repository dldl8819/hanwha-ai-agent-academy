# 함수 (def)

## 함수란?
특정 작업을 수행하는 코드 블록에 이름을 붙여 재사용할 수 있도록 만든 것.

```python
# 정의하기
def 함수이름():
    실행할 코드들...
    return 결과값

# 호출하기
함수이름()

# 매개변수가 있는 함수
def 함수이름(매개변수, 매개변수, ...):
    실행할 코드들...
    return 결과값

변수 = 함수이름(인자, 인자, ...)
```

매개변수와 리턴값의 유무에 따라 4가지 형태로 작성할 수 있고, 매개변수와 인자의 **개수·순서는 원칙적으로 일치**해야 한다(단, 키워드 인자를 쓰면 순서를 바꿀 수 있다).

## 함수 타입 힌트 구조
```python
def 함수이름(매개변수1: 타입, 매개변수2: 타입, ...) -> 리턴타입:
    실행할 코드들...
    return 리턴값  # return이 없으면 리턴타입에 None을 적어주면 된다
```
- 각 매개변수 뒤에 `: 타입` 추가
- 리턴 타입은 소괄호와 콜론 사이에 `-> 리턴타입`
- 리턴 값이 없으면 `-> None`

## 매개변수 기본값
```python
def greeting(name="아무개"):
    print(f"안녕하세요, {name}님")
greeting()

# default 값이 있는 매개변수는 일반 매개변수 뒤쪽에 배치
def greeting(age, name="아무개"):
    print(f"안녕하세요, {age}세이신 {name}님")
greeting(20)
```

## 키워드 인자
```python
# 매개변수와 인자의 순서는 원칙적으로 일치해야 한다.
def info(name, age):
    print(f"{name}님의 나이는 {age}입니다.")
info("민식", 20)

# 키워드 인자를 사용하면 인자의 순서를 바꿀 수 있다.
info(age=20, name="민식")
```

## 가변 인자 `*args`, `**kwargs`
```python
# 넘겨주는 데이터가 여러 개일 때 하나의 매개변수로 받고 싶으면 *args 사용
def total(*nums):
    return sum(nums)

total(10, 20, 30, 40, 50)  # 150

def total(num, *args, age=1000):
    print(num, age, args)
    return sum(args)

total(10, 20, 30, 40, 50)  # 10 1000 (20, 30, 40, 50)
```
> 가변 인자는 일반 매개변수 뒤에 배치하고, default 값이 있는 매개변수는 가변 인자보다 뒤에 배치한다.

```python
def show_info(**kwargs):
    for key, value in kwargs.items():
        print(f"{key} : {value}")

show_info(name="Tom", age=20)
show_info(name="Tom", age=20, email="test@test.com")
```
> `**kwargs`도 일반 매개변수 뒤에 배치한다.

## 리턴값 여러 개
```python
def get_name_and_age():
    return "Anne", 35

name, age = get_name_and_age()
```

## 함수도 객체다
```python
def greet():
    print("hello")

def exec_func(func):  # 함수를 매개변수로 받고
    func()             # 매개변수로 호출도 가능

exec_func(greet)  # 함수를 인자로 전달
```

## 랜덤(random)
임의의 수를 다룰 때 `random` 표준 라이브러리를 사용한다.
```python
import random

random.random()        # 0.0 ~ 1.0 미만의 실수 반환
random.randint(1, 7)   # 1 ~ 7 사이의 정수 반환
```
