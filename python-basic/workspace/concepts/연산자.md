# 연산자

연산자 종류에는 산술연산자, 비교연산자, 논리연산자, in 연산자, 삼항연산자, 대입연산자, 복합대입연산자가 있다.

## 산술 연산자
```python
+  -  *  /
```
- `/` : 실수로 결과 나옴 ex. `10 / 3 = 3.33333...`
- `%` : 나머지 값 구하기 ex. `10 % 3 = 1`
- `//` : 몫만 구해주는 연산자 ex. `10 // 3 = 3`

## 비교 연산자
연산 결과가 bool 타입(True/False)으로 나온다.
```python
>   # 크다
>=  # 크거나 같다
<   # 작다
<=  # 작거나 같다
==  # 같다
!=  # 다르다
```

## 논리 연산자
비교 연산자와 동일하게 결과가 bool 타입이고, 비교 연산식을 여러 개 묶어서 판단하고 싶을 때 쓴다.
```python
and  # 양쪽 모두 참이어야 참, 하나라도 거짓이면 거짓
or   # 하나라도 참이면 참, 둘 다 거짓이어야 거짓
not  # 반전 (True -> False, False -> True)
```

## in 연산자
포함 여부를 True/False로 리턴한다. 리스트뿐 아니라 문자열, 튜플, 딕셔너리(키 기준)에도 똑같이 쓸 수 있다.

```python
nums = [1, 2, 3, 4, 5]
print(3 in nums)   # True
print(13 in nums)  # False

string = "hello python"
print("lo py" in string)  # True

dic = {'name': 'pika', 'age': 100}
print('name' in dic)          # True (키만 확인)
print('pika' in dic.values()) # True (값 확인은 .values() 필요)
```

## 삼항 연산자
조건에 따른 값을 한 줄로 표현한다.

```python
<참일 때 값> if <조건식> else <거짓일 때 값>

score = 50
result = "합격" if score >= 60 else "불합격"
print(result)  # 불합격
```

## 대입 연산자 / 복합 대입 연산자
```python
=  # 대입 연산자

+= -= *= /= %=  # 복합 대입 연산자 (산술 + 대입)

i = i + 1  # => i += 1
```
