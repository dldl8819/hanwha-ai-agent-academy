# 예외 처리 (Exception Handling)

## 예외 (Exception)

- 예외는 코드 실행 중 발생하는 오류.
- 프로그램을 강제 종료시키지 않고 처리할 수 있는 것들.

## 예외 처리 문법

```python
try:
    # 예외가 발생할 수 있는 코드들
except 예외클래스:
    # 예외 발생 시 처리할 코드들
```

## 자주 사용하는 예외 클래스

| 예외 클래스 | 발생 예시 |
| --- | --- |
| `ValueError` | `int("abc")` |
| `TypeError` | `"a" + 1` |
| `KeyError` | `mydict["없는키값"]` |
| `IndexError` | 인덱스 번호 에러 |
| `AttributeError` | 속성이 없는 것을 부를 때 `None.age` |
| `FileNotFoundError` | 없는 파일 열 때 |
| `ZeroDivisionError` | 0으로 나눌 때 |
| `UnicodeDecodeError` | 인코딩 불일치 |

관련 예시: [day03/ex24.py](../day03/ex24.py)의 `os.path.exists()`로 미리 확인해서 `FileNotFoundError`를 방지하는 방식도, 결국 예외가 나기 전에 조건으로 걸러내는 방어적 처리의 한 예시다. `try-except`는 그 대안으로, 조건으로 미리 막기 어려운 상황(예: 실행 도중에만 알 수 있는 오류)에서 사용한다.
