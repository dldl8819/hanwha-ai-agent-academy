# 예외 처리 (Exception Handling)

## 예외 (Exception)

- 예외는 코드 실행 중 발생하는 오류.
- 프로그램을 강제 종료시키지 않고 처리할 수 있는 것들.

## 예외 처리 문법

```python
try:
    # 예외가 발생할 수 있는 코드들
except 예외클래스:
    # 예외 발생 시 처리할 코드들
```

## 자주 사용하는 예외 클래스

| 예외 클래스 | 발생 예시 |
| --- | --- |
| `ValueError` | `int("abc")` |
| `TypeError` | `"a" + 1` |
| `KeyError` | `mydict["없는키값"]` |
| `IndexError` | 인덱스 번호 에러 |
| `AttributeError` | 속성이 없는 것을 부를 때 `None.age` |
| `FileNotFoundError` | 없는 파일 열 때 |
| `ZeroDivisionError` | 0으로 나눌 때 |
| `UnicodeDecodeError` | 인코딩 불일치 |

관련 예시: [day03/ex24.py](../day03/ex24.py)의 `os.path.exists()`로 미리 확인해서 `FileNotFoundError`를 방지하는 방식도, 결국 예외가 나기 전에 조건으로 걸러내는 방어적 처리의 한 예시다. `try-except`는 그 대안으로, 조건으로 미리 막기 어려운 상황(예: 실행 도중에만 알 수 있는 오류)에서 사용한다.

### 예외 클래스 계층 구조

- 모든 예외는 `BaseException`을 최상위로 하는 클래스 계층을 이룬다.
- `Exception`은 프로그램에서 다루는 대부분의 예외의 부모 클래스이자, **모든 예외를 한 번에 처리하고 싶을 때 사용할 수 있는 클래스**다.

```
BaseException
    Exception
        ValueError
        OSError   # FileNotFoundError, ...
        ...
```

- `except Exception as e:`처럼 잡으면 위 계층에 속한 거의 모든 예외를 한 번에 처리할 수 있다. 다만 어떤 예외인지 구분해서 다르게 처리하고 싶다면, `ValueError`처럼 더 구체적인 예외 클래스를 먼저 잡고, 마지막에 `Exception`으로 나머지를 잡는 순서로 작성한다.

### `else` - `finally`

```python
try:
    # 예외가 발생할 수 있는 코드들
except 예외클래스:
    # 예외 발생 시 처리할 코드들
else:
    # 예외 없이 성공했을 때 실행
finally:
    # 예외 발생 여부와 상관없이 항상 실행
```

- `else`: try 블록이 예외 없이 성공했을 때만 실행.
- `finally`: 예외가 발생하든 안 하든 **항상** 실행 (파일 닫기, 리소스 정리 등에 사용).

### 예외 발생시키기 (`raise`)

```python
raise 예외클래스(메시지)
```

- 특정 조건에서 강제로 예외를 발생시키고 싶을 때 사용한다.

```python
class Person:
    def __init__(self):
        self.age = 0

    def set_age(self, v):
        if not isinstance(v, int):
            raise TypeError("입력하신 데이터 타입을 확인해주십시오.")
        if v < 0:
            raise ValueError("나이는 음수가 될 수 없습니다.")
        self.age = v
```

- `except` 블록 안에서 인자 없이 `raise`만 쓰면, 잡았던 예외를 그대로 다시 발생시킨다(원래 예외를 상위로 전파하고 싶을 때 사용).

```python
try:
    p.set_age(-10)
except TypeError as e:
    print(f"예외 발생!! {e}")
    raise   # 잡은 예외를 그대로 다시 던짐
except ValueError as e:
    print(f"예외 발생!! {e}")
```

### 사용자 정의 예외 만들기

- 내장 예외 클래스만으로 표현하기 애매한 상황은 `Exception`을 상속받아 직접 예외 클래스를 만들 수 있다.

```python
class MyException(Exception):
    pass
```

```python
raise MyException("이런저런 예외가 발생했습니다.")
```

```python
try:
    ...
except MyException as e:
    # 예외 처리 메시지 : "이런저런 예외가 발생했습니다."
    print("예외 처리: ", e)
    ...
```

### 예시 (day03/ex26.py)

```python
class MyException(Exception):
    pass

try:
    print("사용자 정의 예외 만들기")
    raise MyException("경고!!예외가 발생했습니다!")
except MyException as e:
    print("예외 처리가 필요합니다. : ", e)
```

- 사용자 정의 예외도 `Exception`을 상속받은 클래스이므로, 지금까지 다룬 `try-except`, `raise`, `except Exception`으로 한 번에 잡기 같은 규칙이 모두 동일하게 적용된다.
