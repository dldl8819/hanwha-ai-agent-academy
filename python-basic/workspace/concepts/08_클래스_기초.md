# 클래스 기초

## 클래스란?
- 클래스는 객체(Object)를 만들기 위한 틀(설계도)이다.
- 속성(변수)과 기능(메서드)을 정의한다.

## 클래스 정의 구조
```python
class 클래스명:
    ... 변수들, 메서드(클래스 내부의 함수)
```
> 클래스명의 첫 글자는 대문자로 만든다.

## 생성자
- 객체가 생성될 때 자동으로 한 번 실행되는 메서드.
- 주로 속성(변수) 초기화에 사용.
- 첫 번째 매개변수는 반드시 `self`.

```python
class 클래스명:
    # 생성자
    def __init__(self, 매개변수들...):
        self.변수명 = 값
```
> `__init__`: 생성자 메서드 / `self`: 객체 자신을 가리키는 키워드 / `self.name = 'pikachu'`처럼 객체에 저장되는 변수(인스턴스 변수)를 생성 / 메서드: 클래스 안에 정의된 함수.

## 변수(속성)의 종류와 Scope

| 변수 종류 | 선언 위치 | 접근 방법 | 설명 | 생성 시점 | 소멸 시점 |
| --- | --- | --- | --- | --- | --- |
| 인스턴스 변수 | 클래스 내부 `self.변수명=값` | `참조변수.변수명` | 객체마다 개별적으로 존재 | `__init__` 등에서 선언 시 | 객체 소멸 시 |
| 클래스 변수 | 클래스 내부 `변수명=값` | `클래스명.변수명` | 클래스 전체에서 공유 | class 정의 시 | 클래스 소멸 시 |
| 지역 변수 | 함수/메서드 내부 | `변수명` | 함수 호출될 때만 존재 | 함수(메서드) 호출 시 | 함수(메서드) 종료 시 |
| 전역 변수 | 함수/클래스 외부 | `변수명` | 모듈(파일) 전체에서 사용 가능 | 파일 자체 import 시 | 프로그램 종료 시 |

```python
class Person:
    # 클래스 변수
    nation = "Korea"
    # 생성자
    def __init__(self):
        print("생성자 호출!")
        # 인스턴스 변수
        self.name = ""
        self.age = 0
        # 지역변수
        x = 10

# 객체 생성 : p1, p2, p3는 참조변수
p1 = Person()
p2 = Person()
p3 = Person()

print(Person.nation)
print(p1.nation)

p1.nation = "UK"  # 인스턴스 변수화 (클래스 변수를 덮어쓰지 않고, p1만의 변수가 새로 생김)
print(Person.nation)  # 여전히 "Korea"
print(p1.nation)       # "UK"
```

클래스 변수는 모든 객체가 공유하지만, `p1.nation = "UK"`처럼 인스턴스에 직접 값을 대입하면 그 객체만의 인스턴스 변수가 새로 만들어져서 클래스 변수를 덮어쓰지 않는다.
