# 변수와 자료형

## 변수와 동적 타입 언어
변수는 값을 저장하는 공간이다. 파이썬은 동적 타입 언어라 변수 선언 시 타입을 따로 지정하지 않아도 된다.

| 정적 타입 언어 | 동적 타입 언어 |
| --- | --- |
| 변수 선언 시 타입 지정 필요 | 타입 자동 추론 |
| Java, C, C++ | Python, JavaScript |

```python
변수명 = 값
```

자료형은 `type(변수)`로 확인할 수 있다.

## 기본 자료형

| 자료형 | 예시 | 설명 |
| --- | --- | --- |
| int | 10 | 정수형 |
| float | 3.14 | 실수형 |
| str | "hello" | 문자열형 |
| bool | True, False | 참/거짓 |
| NoneType | None | 아무 값도 없음 |

### 숫자형(int, float)

| 항목 | 파이썬 사용 예 |
| --- | --- |
| 정수 | 123, -345, 0 |
| 실수 | 123.45, -1234.5, 3.4e10 |
| 8진수 | 0o34, 0o25 |
| 16진수 | 0x2A, 0xFF |

### 문자형(str)
연속된 문자들의 나열이고, 순서가 있어서 인덱스 번호로 글자 한 개만 뽑아올 수 있다. 한 번 만들면 값을 바꿀 수 없는(immutable) 특징이 있다.

```python
"hello"
'hello'

# h e l l o
# 0 1 2 3 4  ← 인덱스 번호

hello[0]  # -> 'h'
```

### 불 자료형(bool)
```python
True   # 참
False  # 거짓
```

## 복합 자료형(컬렉션)

| 자료형 | 예시 | 설명 |
| --- | --- | --- |
| list | [1, 2, 3] | 순서 있고 변경 가능한 자료 모음 |
| tuple | (1, 2, 3) | 순서 있지만 변경 불가능 |
| dict | {"name": "Alice"} | 키-값 쌍 |
| set | {1, 2, 3} | 중복 없는 집합 |

### 리스트(list)
`[]`로 감싸서 만들고, 순서가 있어 인덱스를 사용할 수 있으며, 값을 자유롭게 추가·삭제할 수 있는(mutable) 자료형.

주요 메서드:
```python
.append(값)       # 맨 뒤에 값 추가
.insert(인덱스, 값) # 인덱스 위치에 값 추가
.remove(값)       # 값 삭제
.pop()            # 마지막 값 제거
.sort()           # 정렬
```
- 인덱싱: 리스트 안의 특정 데이터 한 개를 조회 → `[인덱스]`
- 슬라이싱: 리스트 안의 여러 데이터를 잘라서 조회 → `[시작인덱스:끝인덱스]`

### 튜플(tuple)
`( , )`로 감싸서 만들고, 데이터가 한 개일 때는 반드시 쉼표를 붙여야 튜플로 인식된다. 리스트와 달리 한 번 만들면 수정이 불가능(immutable)해서 읽기 전용 데이터에 적합하고, 리스트보다 속도가 빠르다. 함수/메서드에서 여러 값을 한 번에 리턴할 때도 자주 사용된다.

```python
변수명 = (값,)
변수명 = (값1, 값2, 값3, ...)
변수명 = 값1, 값2, 값3, ...
```
인덱싱·슬라이싱은 리스트와 거의 동일하게 사용할 수 있다.

### 딕셔너리(dict)
`{키: 값}` 형태로 데이터를 저장하고, 여러 쌍도 `{키1: 값1, 키2: 값2, ...}`처럼 저장할 수 있다. 파이썬 3.7부터는 순서도 보장된다. 키는 중복될 수 없지만 값은 중복 가능하고, 키를 이용해 값을 조회하는 구조.

주요 메서드:
```python
.get(키)   # 키로 값 조회
.keys()    # 키 리스트 조회
.values()  # 값 리스트 조회
.items()   # 키-값 쌍 조회
.clear()   # 데이터 전체 삭제
```

### 집합(set)
`{}` 또는 `set()`으로 만들고, 순서가 없어 인덱스를 쓸 수 없는 대신 값이 자동으로 중복 제거된다. 중복 제거용 필터로 많이 쓰이고, 합집합·교집합·차집합 같은 집합 연산도 가능하다.

주요 메서드:
```python
.add(값)      # 값 추가
.discard(값)  # 값 삭제
.remove(값)   # 값 삭제
.clear()      # 모든 값 삭제
.update(값)   # 여러 값 수정/추가
```

집합 연산:
```python
a = {1, 2, 3}
b = {3, 4, 5}
print(a | b)  # 합집합 -> {1, 2, 3, 4, 5}
print(a & b)  # 교집합 -> {3}
print(a - b)  # 차집합 -> {1, 2}
```
