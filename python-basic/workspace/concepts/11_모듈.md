# 모듈 (Module)

## 개념

- 파이썬 파일 `.py` 하나를 의미한다.
- 기능별로 코드를 분리해서 재사용하기 좋게 만든 파일 단위.
- 예: `abc.py`, `math_utils.py`

## 사용 방법

### 모듈 만들기

```python
# math_utils.py
def add(a, b):
    return a + b
```

### 모듈 사용하기

```python
# test.py
import math_utils

result = math_utils.add(1, 2)
print(result)   # 3
```

- `import 모듈명`으로 가져오면 `모듈명.함수명()` 형태로 그 모듈 안의 함수/변수/클래스를 사용할 수 있다.
- 모듈명은 확장자(`.py`)를 뺀 파일명 그대로 쓴다.

### 모듈 import 방법

| 방식 | 예시 | 설명 |
| --- | --- | --- |
| 전체 불러오기 | `import module` | 모듈 전체를 불러옴 |
| 별명 사용 | `import module as m` | 이름 짧게 줄이기 |
| 함수만 가져오기 | `from module import func` | 필요한 함수만 가져오기 |
| 모든 요소 가져오기 | `from module import *` | 가독성 저하 위험 있음 |
