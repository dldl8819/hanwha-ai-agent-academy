# 상속 (Inheritance)

- 부모 클래스의 속성과 메서드를 자식 클래스가 물려받아 사용한다.
- 메서드 오버라이딩이 가능하다.

## 구조

```python
class 자식클래스명(부모클래스명):
    pass
```

## 예시 (day03/ex20.py)

```python
class Person:
    def __init__(self):
        self.name = "사람"

    def study(self):
        print(f"{self.name}님이 공부를 한다.")

class Heifam(Person):   # self.name, study() 물려받음
    # 오버라이딩
    # 부모로부터 물려받은 기능을 수정하는 것
    # 기존 def study(self): 선언부는 동일해야 한다.
    def study(self):
        print(f"{self.name}님이 Python 공부를 한다.")

member = Heifam()
print(member.name)      # 물려받은 상태 그대로 출력 -> "사람"
member.study()          # 오버라이딩된 study() 실행 -> "사람님이 Python 공부를 한다."
member.name = "민식"    # 물려받은 변수의 값 수정
member.study()          # "민식님이 Python 공부를 한다."
```

- `Heifam`은 `__init__`을 따로 정의하지 않았기 때문에 부모 `Person`의 `__init__`을 그대로 물려받는다.
- `study()`는 자식 클래스에서 새로 정의(오버라이딩)했기 때문에, `Heifam` 객체는 자신의 `study()`가 호출된다.
