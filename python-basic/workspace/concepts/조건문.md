# 조건문 (if)

| 분류 | 종류 | 설명 |
| --- | --- | --- |
| 조건문 | `if`, `elif`, `else` | 조건에 따라 코드 실행 분기 |

## 구조

```python
# 기본형
if 조건식:
    조건이 참일 때 실행할 코드들...

# else 포함
if 조건식:
    조건이 참일 때 실행할 코드들...
else:
    조건이 거짓일 때 실행할 코드들...

# elif로 조건 여러 개
if 조건식1:
    조건1이 참일 때 실행할 코드들...
elif 조건식2:
    조건2가 참일 때 실행할 코드들...
else:
    모든 조건이 거짓일 때 실행할 코드들...
```

- 들여쓰기를 꼭 지켜야 한다.
- `else`는 옵션이며, 조건식 없이 바로 콜론(`:`)만 붙인다.
- `elif`는 조건이 여러 개일 때 사용한다.

## 예시

```python
score = 15
if score >= 90:
    print("A")
elif score >= 80:
    print("B")
elif score >= 70:
    print("C")
else:
    print("재시험")

# 중첩 조건
age = 20
is_student = True

if age >= 18:
    if is_student:
        print("성인이며 학생입니다.")
    else:
        print("그냥 성인입니다.")
else:
    print("미성년자 입니다.")
```
