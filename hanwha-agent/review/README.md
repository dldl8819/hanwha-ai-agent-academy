# 복습 — 폰에서 오프라인으로

개념 노트 49편과 회상 카드를 **HTML 한 장**으로 묶는다. 인터넷 없이 열린다.

```bash
python review/만들기.py
```

```text
review\복습.html  (676 KB)
  노트 49편 · 카드 137장
```

## 폰에 넣기

1. `review/복습.html` 을 **카톡 "나에게 보내기"** 로 보낸다
2. 폰에서 받아 **다운로드**
3. **크롬이나 삼성 인터넷으로 연다** — 파일 관리자·카톡의 내장 뷰어로 열면
   자바스크립트가 안 돌아 화면이 빈다. 파일을 길게 눌러 "다른 앱으로 열기"에서 브라우저를 고른다
4. 브라우저 메뉴에서 **홈 화면에 추가**

주소창 없이 앱처럼 열린다. 이후로는 비행기 모드에서도 그대로 된다.

### 폰에서 화면이 비어 보일 때

먼저 **노트 탭도 비었는지** 본다.

| | 뜻 | 할 일 |
| --- | --- | --- |
| 카드·노트 둘 다 빔 | 자바스크립트가 아예 안 돈다 | 내장 뷰어 말고 브라우저로 연다 |
| 오류 상자가 뜸 | 스크립트가 중간에 멈췄다 | 상자에 찍힌 메시지를 그대로 전달 |
| 카드만 빔 | 오늘 몫을 이미 다 봤다 | 정상. "오늘 몫은 끝났습니다"가 뜬다 |

빈 화면이 나오지 않도록 최상위에 오류 표시를 달아 두었다. 그래도 아무것도 안 나오면
자바스크립트가 실행되지 않은 것이다.

갱신은 새로 만들어 다시 보내면 된다. **진도는 안 날아간다** — 진도가 파일이 아니라
브라우저 저장소(localStorage)에 있기 때문이다.

## 쓰는 법

| | |
| --- | --- |
| 오늘 카드 | 질문 → `답 보기` → `알았다` / `몰랐다` |
| 노트 | 49편 전문. 카드 답의 "원문 보기"로도 들어간다 |
| ◐ | 밝게 / 어둡게 |

`알았다`를 누르면 다음에 보는 간격이 늘고, `몰랐다`를 누르면 처음으로 돌아간다.

```text
1일 → 3일 → 7일 → 21일 → 60일
```

하루에 새로 꺼내는 카드는 10장이다. 복습할 카드가 많은 날은 새 카드가 그만큼 덜 나온다.
돌려 보면 하루 10~17장, 평균 11장이다.

## 카드 추가

`review/카드.md` 에 세 줄만 쓰면 된다.

```markdown
## 47_벡터와_코사인_유사도
### 코사인 유사도가 거리가 아니라 각도를 보는 이유는?
문장이 길면 벡터가 커진다. 내적만 쓰면 긴 문서가 이긴다.
```

- `##` 은 `concepts/` 의 노트 파일 이름(확장자 없이). 안 맞으면 만들 때 경고가 뜬다
- `###` 이 질문, 그 아래가 답. 답에는 코드블록·표를 써도 된다
- 카드 id 를 질문 글자로 만든다 → **답을 고치면 진도가 유지되고, 질문을 고치면 새 카드가 된다.**
  사이에 끼워 넣거나 순서를 바꿔도 진도는 안 밀린다

노트를 새로 쓴 날은 카드도 같이 추가하고 다시 만든다. 카드가 없는 노트는
만들 때 번호로 알려 준다.

## 손볼 만한 값

`review/만들기.py` 의 템플릿 안에 있다.

```javascript
var 간격 = [1, 3, 7, 21, 60];   // 상자별로 며칠 뒤에 다시 보나
var 신규 = 10;                   // 하루에 새로 꺼내는 장수
```

## 아이폰

아이폰은 **로컬 파일을 홈 화면에 추가할 수 없다.** 파일 앱에 넣어 두고 눌러도
미리보기로 열리고, 그 미리보기는 진도(localStorage)를 안 남긴다.
구글 드라이브에 올려도 마찬가지다 — 드라이브 앱의 내장 뷰어로 열리고 사파리로 넘어가지 않는다.

그래서 아이폰에서는 **주소가 있어야 한다.** GitHub Pages 로 올린다.

### 한 번만 하는 설정

1. 저장소 → Settings → Pages → Source 를 **GitHub Actions** 로
2. `main` 에 push (워크플로가 `concepts/`·`카드.md`·`만들기.py` 변경을 감시한다)
3. Actions 탭에서 초록불 확인 → 주소가 나온다

### 폰에서

1. **사파리로** 그 주소를 연다 (크롬 말고. 사파리만 홈 화면 추가가 된다)
2. 공유 버튼 → **홈 화면에 추가**
3. 홈 화면 아이콘으로 한 번 연다 → 서비스 워커가 페이지를 통째로 저장한다

이 뒤로는 비행기 모드에서도 열린다. 주소창 없이 앱처럼 뜨고 진도도 제대로 남는다.

갱신은 **push 한 번**이면 된다. 다음에 인터넷이 있을 때 새 내용으로 바뀐다.

만든 HTML 은 저장소에 커밋하지 않는다. 678 KB 가 매일 바뀌면 히스토리가 그만큼 불어나므로,
워크플로가 Actions 안에서 만들어 바로 배포한다.

> 저장소가 public 이라 주소를 아는 사람은 볼 수 있다. 노트는 이미 GitHub 에 공개돼 있어서
> 새로 공개되는 내용은 없다. 주소를 내보내기 싫으면 아래 Obsidian 쪽을 쓴다.

### 직접 확인하려면

```bash
python review/만들기.py --pages
python -m http.server 8080 -d review/_site
```

`file://` 로 열면 서비스 워커가 등록되지 않는다(브라우저가 막는다). 로컬 서버로 확인한다.

## Obsidian 으로 보기

노트가 이미 `[[위키링크]]` 형식이라 Obsidian 에서 그대로 열린다.

**아이폰에서는 구글 드라이브를 보관함으로 쓸 수 없다.** Obsidian iOS 가 고를 수 있는 자리는
"이 아이폰 안" 과 iCloud 둘뿐이다. 드라이브가 파일 앱에 보이더라도 보관함으로는 안 열린다.

iCloud 를 안 쓰려면 이렇게 한다.

1. Obsidian 에서 **"이 아이폰 안"** 에 보관함을 만든다
2. 파일 앱에서 구글 드라이브 → `concepts/` 를 골라 **복사**
3. `On My iPhone / Obsidian / <보관함>` 에 붙여넣는다

드라이브를 보관함이 아니라 **운반 수단**으로 쓰는 것이다. 붙여넣은 뒤로는 완전 오프라인이고,
갱신할 때마다 이 복사를 다시 한다.

회상 카드까지 쓰려면 한 단계 더 있다.

```bash
python review/만들기.py --obsidian
```

`review/복습카드_옵시디언.md` 가 나온다. 이걸 보관함 안에 넣고
**설정 → 커뮤니티 플러그인 → Spaced Repetition** 을 켜면 왼쪽 리본 아이콘에서 카드가 돈다.

형식은 플러그인 규칙을 따른다.

```markdown
코사인 유사도가 거리가 아니라 각도를 보는 이유는?
?
문장이 길면 벡터가 커진다. 내적만 쓰면 긴 문서가 이긴다.
```

| | HTML 한 장 | Obsidian |
| --- | --- | --- |
| 설치 | 없음 | 앱 + 플러그인 |
| 노트 읽기 | 됨 | 됨. 검색·백링크가 낫다 |
| 회상 카드 | 됨 | 플러그인 켜야 됨 |
| 폰에 넣기 | 파일 하나 | 폴더 통째로 |
| 갱신 | 파일 다시 보내기 | 폴더 다시 동기화 (안드로이드는 복사, 아이폰은 iCloud 또는 유료 Sync) |
| 진도 | 브라우저 저장소 | 노트 파일에 기록 — 되돌려 받으면 PC 에서도 이어진다 |

둘은 배타적이지 않다. 같은 `review/카드.md` 에서 둘 다 나온다.

## 아는 한계

- **밀린 복습은 안 잘린다.** 일주일 쉬면 그날 밀린 게 한꺼번에 나온다
- 진도는 그 브라우저에만 쌓인다. 폰을 바꾸거나 브라우저 데이터를 지우면 처음부터다
- `review/복습.html` 은 커밋하지 않는다(`.gitignore`). 만드는 법만 저장소에 둔다
- 만들 때 `markdown-it-py` 가 필요하다. 결과물은 아무것도 필요 없다
