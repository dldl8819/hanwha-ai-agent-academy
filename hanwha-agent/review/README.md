# 복습 — 주소 하나로

개념 노트와 회상 카드를 HTML 한 장으로 묶어 Claude 아티팩트로 올린다.
폰에서는 주소만 열면 된다. 진도와 기록은 서버에 쌓여 PC 와 폰이 같은 것을 본다.

```bash
python review/아티팩트.py
```

```text
review\복습_아티팩트.html  (867 KB)
  노트 60편 · 카드 242장
```

만든 파일을 아티팩트로 올린다. 카드가 늘면 다시 만들어 **같은 주소에** 올린다.
진도는 페이지가 아니라 저장소에 있으므로 덮어써도 남는다.

## 쓰는 흐름

| | |
| --- | --- |
| 카드 쓰기 | `review/카드.md` 에 `## 노트파일명` + `### 질문` + 답 |
| 묶기 | `python review/아티팩트.py` |
| 올리기 | 만들어진 HTML 을 같은 아티팩트 주소에 다시 올린다 |
| 보기 | 폰에서 그 주소를 즐겨찾기 |

## 화면 네 개

- **오늘** — 복습할 카드를 한 장씩. 답을 보기 전에 이 카드가 몇 번째 상자에
  있는지 막대로 보여 준다. 「다시」를 누르면 0번 상자로 돌아가고 그날 안에 한 번 더 나온다.
- **기록** — 지금까지 본 장수, 연속 학습일, 기억남 비율, 최근 60일 막대.
- **약한 곳** — 틀린 횟수가 많은 카드와, 노트별 오답률. 다시 읽을 노트를 고르는 데 쓴다.
- **노트** — 개념 노트 본문. 본문 안의 `[[위키링크]]` 는 그 노트로 바로 넘어간다.

## 간격 반복

```python
STEPS = [1, 3, 7, 21, 60]   # 맞히면 다음 상자로, 그만큼 뒤에 다시 본다
NEW_PER_DAY = 10            # 하루에 새로 꺼내는 장수
```

맞히면 한 상자 올라가고 틀리면 0번으로 돌아간다. `아티팩트.py` 위쪽에서 고친다.

## 카드 id 는 질문 글자로 만든다

```python
"id": hashlib.sha1(질문.encode("utf-8")).hexdigest()[:10]
```

카드를 사이에 끼워 넣어도 기존 카드의 진도가 밀리지 않는다.
**답을 고쳐도 진도가 유지되고, 질문을 고치면 새 카드가 된다.**

## 진도는 어디에 쌓이나

아티팩트의 `db` 기능에 둔다. 공유 경로라 기기 사이에 이어지고, 나중에 집계를 꺼내 볼 수도 있다.

| 경로 | 내용 |
| --- | --- |
| `cards/{카드id}` | `box` `due` `right` `wrong` `last` `note` |
| `days/{YYYY-MM-DD}` | `seen` `right` `wrong` |

쓰기는 문서마다 한 번에 하나씩 보낸다. 겹쳐 보내면 나중 것이 이기는데 어느 쪽이
나중인지 보장이 없다. 하루 집계는 카드를 넘길 때마다 같은 문서를 건드리므로
손이 멈춘 뒤 한 번만 쓴다.

로그인하지 않고 열면 `claude.use("db")` 가 `null` 을 돌려준다. 그때는 진도를
저장하지 않는다고 화면에 적고, 노트 탭은 그대로 읽을 수 있게 둔다.

## 화면이 비어 보일 때

노트 본문에 `</script>` 나 줄 구분자(U+2028)가 들어가면 브라우저가 거기서
스크립트를 끊는다. `스크립트안전()` 이 그 셋을 바꿔 싣는다.

노트 54 는 cp949 를 utf-8 로 읽으면 어떻게 보이는지를 예시로 담고 있어 깨진
글자(U+FFFD) 자체가 본문이다. 아티팩트는 그 문자를 사고로 보고 발행을 거절하므로
생성기가 엔티티로 바꿔 싣는다.

## 전에 쓰던 오프라인 방식

HTML 을 파일로 폰에 옮겨 `localStorage` 에 진도를 쌓는 방식이었다
(`만들기.py`, GitHub Pages 워크플로). 카드가 늘 때마다 파일을 다시 옮겨야 했고
진도가 기기마다 따로 쌓여 2026-10-08 에 걷어냈다. 필요하면 git 이력에 있다.
