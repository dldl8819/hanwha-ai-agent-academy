# 네트워크와 인터넷 기초

## 네트워크

데이터를 전송할 수 있는 통신망이다.

- **노드(Node)**: 네트워크에 연결된 모든 장치
- **호스트(Host)**: 노드 중에서, 다른 노드에게 하나 이상의 서비스를 제공해주는 노드
- **프로토콜(Protocol)**: 데이터를 언제, 어떤 형식으로 주고받을지에 대한 약속

네트워크 유형:

| 유형 | 범위 |
| --- | --- |
| LAN (Local Area Network) | 같은 네트워크 안에서의 통신 |
| WAN (Wide Area Network) | 내부에서 외부로 나가는 통신 |

## 인터넷과 웹

인터넷은 컴퓨터들이 TCP/IP 프로토콜로 서로 연결되어 정보를 주고받는 전 세계 규모의 네트워크다. 웹(Web, World Wide Web)은 그 인터넷 서비스 중 하나로, 정보를 공유하는 공간을 말한다 — 인터넷 안에 웹, 이메일, 파일 송수신(FTP), 텔넷(Telnet) 등이 포함되는 관계다.

### 웹 동작 원리 — 클라이언트/서버

웹은 클라이언트-서버 방식으로 동작한다.

- 클라이언트(Client): 요청하는 쪽, 웹 브라우저
- 웹 서버(Web Server): 서비스를 제공하는 쪽 (Apache, Tomcat, JEUS, Nginx, uvicorn 등)

```text
클라이언트(브라우저) ── 요청(request) ──▶ 웹 서버
클라이언트(브라우저) ◀── 응답(response) ── 웹 서버(uvicorn)
```

전 세계 컴퓨터가 얽혀 있는 인터넷 망에서, 정확한 도착지를 모르면 요청을 전달할 수 없다. 그래서 클라이언트가 원하는 서버에 정확히 요청을 보내려면 그 서버의 정확한 주소(IP Address)가 있어야 한다.

## IP Address

통신하는 모든 기계는 네트워크상에서 자신을 유일하게 식별하는 고유 주소(IP 주소)를 가진다.

| 버전 | 구성 |
| --- | --- |
| IPv4 | 32비트 2진수, 보통 8비트씩 4부분으로 나눠 10진수로 표기 |
| IPv6 | 128비트 |

```bash
# 내 PC의 (내부) IP 주소 확인
ipconfig
ipconfig -all  # 더 자세한 정보
```

외부(공인) IP 주소는 https://ip.pe.kr/ 같은 사이트에서 확인할 수 있다.

### 패킷과 IP 프로토콜의 한계

데이터는 패킷(packet) 단위로 쪼개져 전송된다(편지봉투에 비유). IP 프로토콜 자체는 아래 한계를 가진다.

- **비연결성**: 받을 대상이 없거나 서비스 불능 상태여도 일단 패킷을 전송한다.
- **비신뢰성**: 중간에 패킷이 사라지거나, 순서가 뒤바뀌어 도착해도 IP는 이를 보장해주지 않는다.
- **프로그램 구분 불가**: 같은 IP를 쓰는 서버에서 여러 애플리케이션이 통신 중이면, IP만으로는 어느 프로그램에게 전달해야 할지 구분이 안 된다.

이 한계들을 보완하기 위해 TCP와 Port가 쓰인다.

## TCP / UDP

인터넷 프로토콜 스택은 여러 계층으로 나뉘는데(OSI 7계층을 실무에서 단순화한 4계층 구조), 그중 전송 계층을 담당하는 대표적인 프로토콜이 TCP와 UDP다.

| | TCP (Transmission Control Protocol) | UDP (User Datagram Protocol) |
| --- | --- | --- |
| 연결 방식 | 연결 지향 (3-way handshake로 연결 수립) | 비연결형 |
| 신뢰성 | 데이터 전달 보증, 순서 보장 | 보증·순서 보장 없음 |
| 특징 | 데이터를 세그먼트 단위로 분할해 전송 | 대신 전송 속도가 빠름 |
| 쓰이는 곳 | 대부분의 웹 통신(HTTP 등), 신뢰성이 중요한 경우 | 스트리밍처럼 속도가 더 중요한 경우 |

## Port

같은 IP 안에서 여러 서비스가 동시에 실행돼도 서로 충돌하지 않도록, 데이터를 주고받는 통로를 포트 번호로 구분한다. IP가 "어느 은행 지점"이라면, Port는 "그 지점의 어느 창구(예금창구/대출창구...)"에 해당한다.

- 포트 번호 범위: `0 ~ 65535`
- `0 ~ 1023`은 이미 널리 쓰이는 well-known 포트라 임의 지정 시 피한다.

| 서비스 | 포트 |
| --- | --- |
| HTTP | 80 |
| HTTPS | 443 |
| FTP | 20, 21 |
| TELNET | 23 |
| SSH | 22 |

```bash
# 사용 중인 포트 확인
netstat -a
```

## DNS (Domain Name System)

IP 주소는 사람이 외우기 어렵고 바뀌는 경우도 있어서, 기억하기 쉬운 도메인명을 대신 사용한다. DNS는 전화번호부처럼 도메인명과 IP 주소를 매핑해두고, 도메인명으로 요청이 오면 해당 IP 주소를 찾아서 알려주는 역할을 한다.
