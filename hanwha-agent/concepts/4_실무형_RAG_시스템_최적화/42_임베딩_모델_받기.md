# 임베딩 모델 받기

[[33_RAG_개요]] ④ 임베딩은 글자를 숫자 배열로 바꾸는 단계다. 그 일을 할 모델을 **내 컴퓨터에 내려받아** 둔다.

## 왜 로컬 모델인가

임베딩도 API 로 부를 수 있다(OpenAI · Cohere · Upstage). 그런데 로컬을 골랐다.

| | API | 로컬 |
| --- | --- | --- |
| 문서가 나가는가 | **나간다** | 안 나간다 |
| 비용 | 문서 수에 비례 | 0 (전기값) |
| 준비 | 키 하나 | **4.3GB 내려받기** |
| 속도 | 네트워크에 달림 | 내 기계에 달림 |

사내 규정 문서가 대상이다. 대외비 등급이 섞여 있는데([[27_구조화_출력]]의 `security_level`) 그걸 바깥으로 보내는 것은 **기술 선택이 아니라 보안 결정**이다([[41_기술_스택_지도]]).

그리고 임베딩은 문서를 올릴 때 **전부 한 번씩** 돈다. 문서가 늘면 호출도 그만큼 는다. LLM 호출처럼 질문당 한 번이 아니다([[32_사용량과_원가_기록]]).

## 두 모델

| 모델 | 만든 곳 | 특징 |
| --- | --- | --- |
| `nlpai-lab/KURE-v1` | 고려대 | 한국어에 맞춰 만든 것 |
| `BAAI/bge-m3` | BAAI | 70개 이상 언어 |

둘 다 받는 이유는 **비교하려고**다. 한국어 전용이 실제로 더 잘하는지는 우리 문서로 재 봐야 안다.

`KURE` 는 v2 가 있는데 **v1 을 받았다.** 크기가 더 크고 쓰는 법도 달라서, 지금은 비교 축을 하나만 바꾸는 쪽이 맞다.

## 받는 방법

### 1. 사이트에서 하나씩 — 비추천

Hugging Face 페이지에서 파일을 클릭해 받는다. 파일이 열 개 남짓이고 하나가 2.2GB 라 **빠뜨리기도 쉽고 이어받기도 안 된다.**

### 2. 파이썬으로 — `snapshot_download()`

```bash
python -m pip install "huggingface-hub>=1.5,<2"
```

```python
from huggingface_hub import snapshot_download

snapshot_download(
    repo_id="nlpai-lab/KURE-v1",
    local_dir=경로,
    allow_patterns=[...],      # 이것만 받는다
)
```

### 3. 터미널로 — `hf download`

```bash
hf download nlpai-lab/KURE-v1 --local-dir 경로 --exclude "패턴"
```

로그인도 토큰도 필요 없다. 두 저장소 모두 공개이고 MIT 다.

## 받는 스크립트

수업에서 배포한 `sandbox/w5/day02/download_models.py` 를 썼다. 그냥 `snapshot_download` 한 줄이 아니라 **몇 가지 판단이 들어 있다.**

### 저장소 전체를 받지 않는다

```python
"files": [
    "pytorch_model.bin",
    "config.json",
    "tokenizer.json",
    ...
],
```

`allow_patterns` 로 필요한 것만 집는다. **`bge-m3` 는 `onnx/` 에 같은 가중치 사본이 또 있다(2.27GB).** 전체를 받으면 쓰지도 않는 2.27GB 를 더 받는다.

### 크기를 바이트까지 대조한다

```python
"sizes": {"pytorch_model.bin": 2_271_145_830, "tokenizer.json": 17_098_108},
```

```text
크기다름: pytorch_model.bin (1,402,653,184 B · 기대 2,271,145,830 B)  ← 받다가 끊긴 것
```

**받다가 끊겨도 파일은 남는다.** 이름만 보면 다 있는 것처럼 보이는데 내용이 잘려 있다. 이것도 어제 본 "에러가 나지 않는 실패"([[39_문서_파싱]])와 같은 종류라, 크기를 재는 것이 유일한 확인 방법이다.

### 끊기면 이어 받는다

```python
for attempt in range(1, 4):
    try:
        snapshot_download(...)
        break
    except Exception as e:
        print(f"  {attempt}회차 실패: {type(e).__name__}: {e}")
        if attempt == 3:
            ...
        time.sleep(10)
```

[[28_가드와_재시도_폴백]]의 재시도와 같은 모양이다. 다른 점은 **받은 만큼이 남아 있어서 다시 부르면 이어서 받는다**는 것이다. 처음부터 다시 받지 않는다.

`HF_HUB_DOWNLOAD_TIMEOUT` 기본값이 10초라 GB 파일에서는 끊긴다. 60초로 올려 두는데, **`import` 하기 전에** 환경변수를 바꿔야 먹는다.

```python
os.environ.setdefault("HF_HUB_DOWNLOAD_TIMEOUT", "60")
...
from huggingface_hub import snapshot_download      # 그 다음에 import
```

### 세 가지 모드

| | 하는 일 |
| --- | --- |
| (기본) | 받고 → 확인 |
| `--check` | 받지 않고 확인만 (배포본을 받은 사람) |
| `--smoke` | 확인 + 실제로 열어 문장 20개 임베딩 |

`--smoke` 는 `HF_HUB_OFFLINE=1` 을 켜고 돈다. **인터넷을 타지 않는 조건에서 열리는지**를 보는 것이라, 받는 것과 쓰는 것을 따로 확인한다.

## 어디에 두는가

```text
workspace/
├── hanwha-agent/        ← 저장소
│   ├── backend/
│   └── sandbox/w5/day02/download_models.py
└── models/              ← 저장소 밖, 같은 층
    ├── KURE-v1/   2.2GB
    └── bge-m3/    2.2GB
```

**저장소 안에 두지 않는다.** 4.3GB 를 커밋하면 clone 이 불가능해지고, 한 번 들어가면 히스토리에서 빼기도 어렵다.

`.gitignore` 에 넣어 두었다.

```text
# 임베딩 모델 가중치 — 4.3GB. 받는 법은 sandbox/w5/day02/download_models.py 에
models/
```

저장소에는 **받는 법**만 있고 **받은 것**은 없다. `.env` 를 올리지 않고 `config.py` 에 필요한 키 이름만 적어 둔 것과 같은 판단이다([[01_개발환경설정]]).

스크립트가 기본 경로를 잡는 방식도 그 규칙을 따른다.

```python
def default_dest() -> Path | None:
    here = Path.cwd()
    if (here / "backend").is_dir() and (here / "pyproject.toml").is_file():
        return here.parent / "models"
    return None
```

**프로젝트 루트에서 실행했는지를 두 파일로 확인**하고, 맞으면 그 옆에 둔다. 아니면 `None` 을 돌려주고 안내한다 — 엉뚱한 자리에 4.3GB 를 쏟지 않기 위해서다.

## 확인

```text
모델 폴더: C:\workspace\models
  v KURE-v1  C:\workspace\models\KURE-v1  (2.27 GB)
  v bge-m3   C:\workspace\models\bge-m3   (2.27 GB)
```

`1_Pooling/config.json` 까지 포함해 열 개 남짓씩 들어 있다. 가중치 파일 이름이 다른 것도 눈에 띈다.

| | 가중치 파일 |
| --- | --- |
| `KURE-v1` | `model.safetensors` |
| `bge-m3` | `pytorch_model.bin` |

`.bin` 은 파이썬 객체를 그대로 저장한 형식이라 **여는 것만으로 코드가 실행될 수 있다.** `safetensors` 는 그게 불가능하도록 만든 형식이다. `bge-m3` 를 열려면 torch 2.6 이상이 필요한 것도 이 때문이다 — 낮은 버전에서 `.bin` 로딩을 막아 두었다.

## 짚어둘 것

받는 데만 4.3GB 다. 이건 **한 번 하는 일**이고, 여기서 하루가 지나가면 내일 임베딩을 못 한다. 그래서 수업이 배포본과 `--check` 를 같이 준비한 것이다.

아직 모델을 **받기만 했고 써 보지는 않았다.** 차원이 1,024 라는 것, 문장 20개에 몇 초 걸리는지는 `--smoke` 나 다음 수업에서 확인한다.
