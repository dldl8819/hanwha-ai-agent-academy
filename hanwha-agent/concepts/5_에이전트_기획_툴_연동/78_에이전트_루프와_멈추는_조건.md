# 에이전트 루프와 멈추는 조건

[[76_정책_필터를_되돌리고_다시_재다]]까지의 `ask()` 는 순서가 코드에 박혀 있었다.

```text
가드 → 검색 → 임계값 판정 → 체인 호출(재시도) → 폴백 → 닫기
```

검색을 할지, 무엇으로 할지, 몇 번 할지를 **코드가 정했다.** 모델은 근거를 받아 문장을
쓰는 마지막 칸 하나만 맡았다. 과목 5 는 그 결정 일부를 모델에게 넘기는 데서 시작한다.

## 관찰 → 판단 → 행동

```text
관찰                 →   판단             →   행동
(질문, 도구 결과)         (모델이 정한다)         (도구 실행 — 우리 코드가 한다)
     ↑                                          │
     └──────────────────────────────────────────┘
```

| 칸 | 누가 | `ask_with_tools` 에서 |
| --- | --- | --- |
| 관찰 | 모델 | `messages` — 질문, 그동안의 assistant 응답, tool_result |
| 판단 | 모델 | 도구를 부를지, 어떤 인자로 부를지 → `tool_use` 블록 |
| 행동 | **우리 코드** | `TOOL_RUNNERS[name](**args, user=user)` |

모델은 도구를 실행하지 못한다. 「이 이름으로 이 인자를 넣어 불러 달라」고 **요청만**
한다. 실행은 서버 쪽 코드가 하고 결과를 다시 넣어 준다. 이 구분이 뒤의 권한 이야기
([[79_도구_정의와_tool_result]])의 바탕이다.

## 루프가 끝나는 조건

둘이다.

| 조건 | 누가 정하나 | 코드 |
| --- | --- | --- |
| 모델이 더 부를 도구가 없다고 한다 | 모델 | `if not calls: break` |
| 왕복 상한에 닿는다 | 우리 | `MAX_TOOL_TURNS = 3` |

둘 다 없으면 무한 루프다. 모델이 「한 번 더 찾아보겠습니다」를 계속할 수 있고
실제로 그랬다([[80_도구_루프를_돌려_보다]]의 해외 출장 질문).

## stop_reason

| 값 | 뜻 | 루프에서 |
| --- | --- | --- |
| `end_turn` | 자연스럽게 멈췄다 | 끝 |
| `tool_use` | 도구를 부르겠다 | 계속 |
| `max_tokens` | 출력 상한에 걸려 잘렸다 | **끝으로 처리된다 — 문제** |
| `stop_sequence` | 우리가 준 정지 문자열이 나왔다 | 안 쓴다 |
| `pause_turn` | 긴 턴을 잠시 멈췄다 | 안 쓴다 |
| `refusal` | 정책 판단으로 멈췄다 | 끝으로 처리된다 |
| `model_context_window_exceeded` | 문맥 창을 넘겼다 | 끝으로 처리된다 |

`ask_with_tools` 는 `stop_reason` 을 보지 않는다. `tool_calls` 가 비었는지만 본다.
그래서 `tool_use` 가 아닌 모든 값이 「답이 끝났다」가 된다. `max_tokens=400` 에서
잘린 답이 그대로 사용자에게 나가는 것을 [[80_도구_루프를_돌려_보다]]에서 확인했다.

## 부작용 등급

도구마다 등급을 붙인다. 실행 방식이 등급으로 갈린다.

| 등급 | 뜻 | 예 | 실행 |
| --- | --- | --- | --- |
| `none` | 조회. 아무것도 바뀌지 않는다 | `search_documents` | 즉시 |
| `internal` | 내부 쓰기. DB 에 반영된다 | `create_draft` | 즉시 + 감사 로그 |
| `external` | 외부 실행. 되돌릴 수 없다 | `send_slack` | **승인 뒤에만** |

`search_documents.SIDE_EFFECT = "none"` 으로 칸만 만들어 두었고 아직 이 값을 읽는
코드는 없다. 도구가 하나뿐이고 조회라서 지금은 문제가 없다. `external` 도구가 들어오는
순간 루프 안에 「승인 대기」 갈래가 필요해진다 — 모델이 요청했다고 바로 실행하면 안 되는
도구가 생기기 때문이다.

## 무엇이 모델에게 넘어갔나

| 결정 | `ask()` | `ask_with_tools()` |
| --- | --- | --- |
| 검색을 할지 | 항상 한다 | 모델 |
| 검색어 | 질문 그대로 (+ Multi-Query) | 모델 |
| 몇 번 | 1번 | 모델 (상한 3) |
| 근거가 부족할 때 | 임계값 미달 → 폴백 | 모델이 「확인하지 못했습니다」를 쓰기를 기대 |
| 출력 형식 | JSON + 스키마 검증 + 재시도 | 문장. 검증 없음 |
| 보안등급 | 코드 | **여전히 코드** |

마지막 두 줄이 중요하다. 넘긴 것과 안 넘긴 것이 섞여 있다. 보안등급은 넘기지 않았다.
근거 부족 판정은 넘기지 않으려 했는데 결과적으로 넘어갔다([[81_출처와_판정이_답과_어긋난다]]).
