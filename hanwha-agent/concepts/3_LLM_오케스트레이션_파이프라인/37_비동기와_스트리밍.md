# 비동기와 스트리밍

Runnable 은 같은 일을 네 가지 방식으로 한다([[34_LangChain_기초]]). 앞에 `a` 가 붙은 것이 비동기다.

| 기본 | 비동기 | 쓰는 법 |
| --- | --- | --- |
| `chain.invoke(...)` | `chain.ainvoke(...)` | `result = await chain.ainvoke(...)` |
| `chain.batch([...])` | `chain.abatch([...])` | `result = await chain.abatch([...])` |
| `chain.stream(...)` | `chain.astream(...)` | `async for piece in chain.astream(...):` |

부품마다 따로 배울 게 없다는 것이 Runnable 규약의 값이다. 프롬프트든 모델이든 내가 만든 람다든 **여덟 가지 메서드가 전부 있다.**

## 노트북에서는 asyncio.run 을 쓸 수 없다

```python
loop = asyncio.get_event_loop()
print("이벤트 루프 :", type(loop).__name__)
print("돌고 있는지 :", loop.is_running())
```

```text
플랫폼 : win32
이벤트 루프 : _WindowsSelectorEventLoop
돌고 있는지 : True
```

**주피터는 이미 이벤트 루프를 돌리고 있다.** 그 위에서 또 돌리려 하면 막힌다.

```python
asyncio.run(hello())
```

```text
RuntimeError: asyncio.run() cannot be called from a running event loop
```

노트북에서는 `await` 를 그냥 쓴다. 셀 자체가 코루틴 안에서 실행되기 때문이다.

```python
value = await hello()      # 노트북에서는 이게 된다
```

실행 환경마다 다르다.

| 어디서 | 어떻게 |
| --- | --- |
| `.ipynb` | `result = await chain.ainvoke(...)` |
| `.py` 스크립트 | `result = asyncio.run(chain.ainvoke(...))` |
| FastAPI `async def` 라우터 | `result = await chain.ainvoke(...)` |

FastAPI 라우터가 노트북과 같은 모양인 것은 우연이 아니다. **둘 다 이미 누가 돌리고 있는 루프 안**이다([[15_비동기_asyncio]]).

## ainvoke 가 된다고 비동기인 것은 아니다

우리 `LLMPort.answer` 는 평범한 동기 함수다. 그런데도 `ainvoke` 가 돈다.

```python
chain = build_answer_chain(MockLLM(), system_prompt=load_prompt("answer_system"))

out       = chain.invoke({"question": "부산 출장 일비는?"})
async_out = await chain.ainvoke({"question": "부산 출장 일비는?"})
```

```text
invoke  : 부산 출장 일비는 1일 5만원입니다.
ainvoke : 부산 출장 일비는 1일 5만원입니다.
```

LangChain 이 비동기 구현이 없는 부품은 **동기 함수를 그대로 불러** 준다. 덕분에 코드가 깨지지 않지만, 대가가 있다 — **그 자리는 진짜로 비동기가 아니다.** 기다리는 동안 다른 요청을 처리하지 못한다.

`await` 를 붙였으니 동시에 돌겠지 하고 넘어가면, 부하를 주기 전까지 아무도 모른다.

## 스트리밍 — 조각 수를 세 보면 안다

가짜 모델로 스트리밍을 확인한다([[34_LangChain_기초]]).

```python
pieces = [p async for p in (prompt | fake_stream_llm() | StrOutputParser()).astream(QUESTION)]
print("조각 개수 :", len(pieces))
print("조각 목록 :", pieces)
```

```text
조각 개수 : 9
조각 목록 : ['일비', ' ', '5만원', ' ', '-', ' ', '숙박', ' ', '실비']
```

조각을 모으면 원문이 그대로 복원된다.

```python
joined = "".join(buf)
```

```text
합친 결과: 일비 5만원 - 숙박 실비
```

### RunnableLambda 하나가 스트리밍을 끊는다

**여기가 오늘의 핵심이다.** 체인 끝에 람다를 하나 붙이고 조각 수를 다시 센다.

```python
decorated = prompt | fake_stream_llm() | StrOutputParser() | RunnableLambda(lambda s: f"[일반] {s}")
```

```text
llm | parser                      : 9
llm | parser | RunnableLambda     : 1
우리 앱 chain.py                   : 1
```

**9개가 1개가 됐다.** 평범한 함수를 감싼 `RunnableLambda` 는 입력이 **다 모일 때까지 기다렸다가** 한 번에 처리한다. 앞에서 아무리 조각으로 흘려보내도 여기서 막힌다.

그리고 우리 앱 체인도 1이다. `build_answer_chain` 끝에 이게 있기 때문이다.

```python
return build_result_chain(llm, **kwargs) | RunnableLambda(lambda r: r.text)
```

즉 **지금 우리 체인은 `stream()` 을 불러도 스트리밍되지 않는다.** 메서드가 있다고 되는 게 아니다.

### 끊기지 않게 하려면 제너레이터로 감싼다

함수가 조각을 받아 조각을 내놓으면 흐름이 이어진다.

```python
def 꾸미기(조각들: Iterator[str]) -> Iterator[str]:
    for s in 조각들:
        yield f"[{s}]"

제너람다 = prompt | fake_stream_llm() | StrOutputParser() | RunnableLambda(꾸미기)
```

```text
+ RunnableLambda(보통 함수)        : 1
+ RunnableLambda(제너레이터 함수)  : 14   ['[일]', '[비]', '[ ]', ...]
```

`return` 이냐 `yield` 냐가 스트리밍 여부를 가른다. **함수의 겉모양은 거의 같은데 동작이 다르다.**

## 짚어둘 것

### 우리 체인이 스트리밍되려면 포트부터 바꿔야 한다

람다를 제너레이터로 고쳐도 지금은 소용없다. `LLMPort.answer` 가 **완성된 `LLMResult` 하나**를 돌려주기 때문이다. 흘려보낼 조각이 애초에 없다.

```text
LLMPort.answer(...) -> LLMResult      # 다 만들어진 결과 한 덩어리
```

스트리밍을 하려면 포트에 `astream` 같은 메서드를 더하고 어댑터가 Anthropic SDK 의 스트리밍 호출을 쓰게 해야 한다. **화면 쪽부터 손대는 게 아니라 포트부터다.**

### 쉼표와 콜론

노트북에 이런 줄이 있었다.

```python
chain.invoke({"question", "부산 출장 일비는?"})     # 콜론이 아니라 쉼표
```

이건 딕셔너리가 아니라 **집합**이다. 그런데 터지지 않고 답이 나온다.

```text
그런데 터지지 않는다. 결과 : 고정 답변
모델이 실제로 받은 질문 : "시스템\n\n{'부산 출장 일비는?', 'question'}"
```

프롬프트에 변수가 **하나뿐**이면 LangChain 이 딕셔너리가 아닌 입력을 그 한 칸의 값으로 넣어 준다. 그래서 집합이 통째로 질문이 됐다. 가짜 모델이 질문을 무시하고 고정 답을 돌려주니 **결과만 보면 멀쩡하다.**

진짜 모델이었다면 엉뚱한 글자를 질문으로 받았을 것이다. 편의 기능이 오타를 덮어 준 경우라, 가짜 모델로 확인할 때는 **모델이 실제로 무엇을 받았는지**도 같이 찍어보는 편이 낫다.

이것도 강사님 자료에는 콜론으로 올바르게 적혀 있었다. **따라 치면서 생긴 오타인데 결과가 멀쩡해서 안 드러났다.** 노트북은 고쳤다.
