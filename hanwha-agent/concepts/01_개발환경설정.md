# 개발 환경 설정

## 작업 폴더 & VSCode

본인 작업 폴더에 `hanwha-agent` 폴더를 만들고 VSCode로 연다. 이후 실습은 이 폴더를 루트로 진행한다.

## 가상환경(venv) 생성

VSCode Terminal에서 파이썬 버전을 먼저 확인한다.

```bash
python --version
py --version
# >> Python 3.12.x
```

프로젝트 전용 가상환경을 만들고 활성화한다.

```bash
# 가상환경 생성
python -m venv .venv

# 가상환경 활성화 (자동으로 안 되면 직접 실행)
.venv\Scripts\activate.bat
# >> (.venv) C:\workspace\hanwha-agent>
```

가상환경을 쓰는 이유는 프로젝트마다 파이썬 패키지 버전을 독립적으로 관리하기 위해서다. `.venv` 폴더는 프로젝트 루트에 생기고, 프롬프트 앞에 `(.venv)`가 붙으면 활성화된 상태다.

## 패키지 매니저(pip) 업그레이드

가상환경을 활성화한 상태에서 pip를 최신 버전으로 올려둔다.

```bash
python -m pip install --upgrade pip
```

## 프로젝트 폴더 구조

`hanwha-agent`는 아래 구조로 구성한다.

```
hanwha-agent/
    backend/                    로직
        app/
            main.py                 서버 시작점
            core/
                config.py
                exceptions.py
                logging.py
            models/                 디비 관련
            schemas/                요청/응답 구조
            repositories/           디비 관련
            services/               비즈니스 로직 처리
            api/
            rag/
            ...
    frontend/                   화면
    sandbox/                    연습코드
        w2/
            day01/
            day02/
        w3/
```

- `backend/`: 서버 로직. `app/main.py`가 서버 시작점이고, `core`(설정·예외·로깅), `models`/`repositories`(DB), `schemas`(요청/응답 구조), `services`(비즈니스 로직), `api`(라우팅), `rag` 등으로 역할을 나눈다.
- `frontend/`: 화면 담당.
- `sandbox/`: 주차(`wN`)/일차(`dayNN`) 단위로 나눈 연습 코드 영역. 본 프로젝트 코드와 분리해서 자유롭게 실습한다.

## Jupyter Notebook

VSCode에 Jupyter 확장을 설치하면 `.ipynb` 파일을 바로 만들고 실행할 수 있다.

1. `.ipynb` 확장자로 파일 생성
2. 우측 상단 `Select Kernel` 클릭 → `Python ...` 선택 → `.venv` 선택

커널을 프로젝트 가상환경(`.venv`)으로 맞춰야 방금 설치한 패키지들이 노트북에서도 그대로 인식된다.

참고: sandbox/w2/day01/00.프로젝트세팅.ipynb
