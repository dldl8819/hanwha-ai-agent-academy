# 병합 셀 — 가려진 칸을 채운다

## 왜 필요한가

엑셀에서 `A2:A3` 을 병합하면, `openpyxl` 은 **첫 칸에만 값을 주고 나머지는 `None`** 으로 준다.

```text
('구분', '1분기', '2분기')
('인프라사업부', 4200000, 3800000)
(None, 1200000, 1400000)        ← 병합으로 가려진 칸
('구매팀', 900000, 1000000)
```

그대로 마크다운 표로 만들면 이렇게 된다.

```text
| 인프라사업부 | 4200000 | 3800000 |
|  | 1200000 | 1400000 |
```

**1,200,000원이 어느 부서 것인지 사라진다.** 예외도 안 나고 표가 그럴듯해서 눌러 보지 않으면 모른다.

## 만들 것

```python
def _fill_merged(ws) -> list[list]:
```

워크시트 하나를 받아 **2차원 리스트**를 돌려준다. 병합 범위에 속한 칸은 전부
그 범위의 왼쪽 위 값으로 채워져 있어야 한다.

## 쓸 수 있는 것

| | 무엇 |
| --- | --- |
| `ws.iter_rows(values_only=True)` | 행을 튜플로 차례로 준다 |
| `ws.merged_cells.ranges` | 병합 범위 목록. 각 원소에 `min_row` `max_row` `min_col` `max_col` 이 있다 |
| `ws.min_row` · `ws.min_column` | 시트에서 값이 시작하는 행·열 번호 |

## 걸리는 곳

**병합 범위는 절대 좌표로 온다.** `min_row` 가 4라면 시트의 4번째 행이라는 뜻이다.
그런데 리스트의 0번째가 시트의 몇 번째 행인지를 알아야 자리를 맞출 수 있다.

여기에 함정이 하나 있다. `ws.min_row` 는 **`iter_rows()` 를 부른 뒤에 값이 바뀐다.**

```python
ws["C3"] = "부서"
print(ws.min_row)                       # 3
list(ws.iter_rows(values_only=True))    # 1행부터 훑으면서 빈 칸이 만들어진다
print(ws.min_row)                       # 1
```

그래서 두 줄의 **순서**에 따라 맞기도 하고 틀리기도 한다. 어느 순서여야 하는지,
왜 그런지 설명할 수 있어야 다 푼 것이다.

## 통과 기준

```bash
python drill/run.py 채점 52_병합셀
```

- 병합된 칸이 왼쪽 위 값으로 채워진다

- A1 에서 시작하지 않는 시트에서도 자리가 맞는다
