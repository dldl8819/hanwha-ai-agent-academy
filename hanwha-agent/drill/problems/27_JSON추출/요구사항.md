# JSON 꺼내기

"JSON 으로만 답하라"고 시켜도 모델은 코드펜스를 두르거나 앞뒤에 설명을 붙인다. 그대로 `json.loads` 에 넣으면 첫 글자에서 실패한다.

## 만들 것

### `_extract_json(text: str) -> dict`

아래를 전부 같은 딕셔너리로 만들어야 한다.

```
{"answer": "7만원", "enough_evidence": true}
```

````
```json
{"answer": "7만원", "enough_evidence": true}
```
````

````
```
{"answer": "7만원", "enough_evidence": true}
```
````

```
말씀하신 규정을 찾아봤습니다.
{"answer": "7만원", "enough_evidence": true}
도움이 되었길 바랍니다.
```

**꺼내지 못하면 예외를 던지지 말고 빈 딕셔너리를 돌려준다.**

## 채점이 보는 것

- 순수 JSON · 코드펜스(`json` 표기 있든 없든) · 앞뒤 설명이 붙은 경우
- JSON 이 **여러 줄**에 걸쳐 있는 경우
- 중괄호가 아예 없으면 `{}`
- 문법이 깨진 JSON 이면 예외 없이 `{}`
- 중첩된 객체·배열이 그대로 살아 있는가

## 왜 이렇게 하는가

빈 딕셔너리를 돌려주는 선택이 중요하다. 여기서 예외를 던지면 부르는 쪽이 **파싱 실패**와 **스키마 위반** 두 가지를 따로 처리해야 한다. 빈 딕셔너리로 돌려주면 둘 다 "검증 실패" 한 갈래로 합쳐지고, 재시도 로직이 하나로 끝난다.

대신 대가가 있다. 조용히 넘어가므로 **로그를 남기지 않으면** 왜 계속 재시도하는지 알 수 없다.
